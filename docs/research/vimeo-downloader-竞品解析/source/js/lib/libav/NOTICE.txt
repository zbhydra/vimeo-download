libav.js — h264-aac-mp3 variant
===============================

The files in this directory are unmodified artifacts from the upstream project:

    Project: libav.js
    Author:  Yahweasel
    Version: v6.5.7.1
    Variant: h264-aac-mp3
    Source:  https://github.com/Yahweasel/libav.js/releases/tag/v6.5.7.1

libav.js is a WebAssembly + JavaScript compilation of FFmpeg libraries
(libavformat, libavcodec, libavfilter, libavutil, libswresample, libswscale).

Files
-----
- libav-6.5.7.1-h264-aac-mp3.wasm.mjs   (ES module glue; loader entry)
- libav-6.5.7.1-h264-aac-mp3.wasm.wasm  (WebAssembly binary)
