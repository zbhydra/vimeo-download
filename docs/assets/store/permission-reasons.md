权限理由说明：

> 权限声明来源：`extension/vite.config.ts` 的 `manifest`，网站范围来源：`extension/src/platforms/registry.ts` 的 `SITE_REGISTRATION.hostPermissions`。
> `permissions` = `storage` / `identity` / `downloads` / `offscreen` / `notifications`；
> `host_permissions` = `https://vimeo.com/*` / `https://www.vimeo.com/*` / `https://player.vimeo.com/*` / `https://*.vimeocdn.com/*`。
> 改 manifest 权限时必须同步本文件。

## 简体中文

**要求 storage 的理由**
保存扩展的设置项（远端配置的本地缓存）、界面语言偏好、登录状态与本地下载历史，以便下次打开时沿用。

**要求 identity 的理由**
完成 Google 登录授权流程。扩展使用 Chrome 自带的授权窗口打开 Google 登录页，并通过 Chrome 为扩展生成的固定回调地址接收登录结果；`identity` 权限是调用该授权窗口与获取回调地址所必需的。

**要求 downloads 的理由**
把下载的文件写入本地磁盘。直连文件和后台处理生成的媒体文件均由 Chrome 的下载管理器保存，扩展通过该权限发起下载并读取下载状态。

**要求 offscreen 的理由**
创建离屏文档，在浏览器后台获取与合成 DASH/HLS 媒体、裁剪自适应媒体及转码 MP3。任务不依赖来源页面或弹窗保持打开；输出临时保存在浏览器本地存储（OPFS），交付下载后清理。

**要求 notifications 的理由**
下载完成或失败时显示系统通知，让用户在弹窗关闭后仍可获知结果。

**要求网站存取权限的理由**
- `https://vimeo.com/*`、`https://www.vimeo.com/*`、`https://player.vimeo.com/*`
  在支持的顶层 Vimeo 视频页上注入下载按钮面板，获取播放器信息（视频 ID、可用画质、音频轨、字幕与封面图地址）；player 子框架中的辅助脚本只提供视频身份。
- `https://*.vimeocdn.com/*`
  获取播放器信息指向的 Vimeo 媒体 CDN 文件、播放清单和媒体分片。

## 繁体中文

**要求 storage 的理由**
儲存擴充功能的設定項目（遠端設定的本機快取）、介面語言偏好、登入狀態與本機下載歷史，以便下次開啟時沿用。

**要求 identity 的理由**
完成 Google 登入授權流程。擴充功能使用 Chrome 內建的授權視窗開啟 Google 登入頁，並透過 Chrome 為擴充功能產生的固定回呼位址接收登入結果；`identity` 權限是呼叫該授權視窗與取得回呼位址所必需的。

**要求 downloads 的理由**
把下載的檔案寫入本機磁碟。直連檔案與背景處理產生的媒體檔案均由 Chrome 的下載管理員儲存，擴充功能透過該權限發起下載並讀取下載狀態。

**要求 offscreen 的理由**
建立離屏文件，在瀏覽器背景取得與合成 DASH/HLS 媒體、裁剪自適應媒體及轉碼 MP3。工作不依賴來源頁面或彈出視窗保持開啟；輸出暫存於瀏覽器本機儲存空間（OPFS），交付下載後清理。

**要求 notifications 的理由**
下載完成或失敗時顯示系統通知，讓使用者在彈出視窗關閉後仍可得知結果。

**要求網站存取權限的理由**
- `https://vimeo.com/*`、`https://www.vimeo.com/*`、`https://player.vimeo.com/*`
  在支援的頂層 Vimeo 影片頁上注入下載按鈕面板，取得播放器資訊（影片 ID、可用畫質、音軌、字幕與封面圖位址）；player 子框架中的輔助指令碼僅提供影片身分。
- `https://*.vimeocdn.com/*`
  取得播放器資訊指向的 Vimeo 媒體 CDN 檔案、播放清單與媒體分片。

## English

**Reason for requesting storage**
To save the extension's settings (a local cache of the remote configuration), interface language, sign-in state and local download history so they persist the next time the extension is opened.

**Reason for requesting identity**
To complete the Google sign-in authorization flow. The extension opens Google's sign-in page in Chrome's own authorization window and receives the result on the fixed callback address that Chrome generates for the extension. The `identity` permission is what allows the extension to open that window and obtain the callback address.

**Reason for requesting downloads**
To write downloaded files to the local disk. Chrome's download manager saves both direct files and media generated by background processing; this permission lets the extension start downloads and read their status.

**Reason for requesting offscreen**
To create an offscreen document for background DASH/HLS fetching and assembly, adaptive media clipping and MP3 transcoding. Tasks do not depend on the source page or popup remaining open. Temporary output is stored in browser-local storage (OPFS) and cleaned up after download delivery.

**Reason for requesting notifications**
To show system notifications when downloads complete or fail, including when the popup is closed.

**Reason for requesting website access**
- `https://vimeo.com/*`, `https://www.vimeo.com/*`, `https://player.vimeo.com/*`
  To inject the download panel into supported top-level Vimeo video pages and retrieve player information (video ID, available qualities, audio tracks, subtitles and cover image URLs). A helper script in player frames supplies video identity only.
- `https://*.vimeocdn.com/*`
  To fetch files, playlists and media segments on Vimeo's media CDN referenced by the player information.

## 日本語

**storage が必要な理由**
拡張機能の設定（リモート設定のローカルキャッシュ）、UI 言語、ログイン状態、ローカルのダウンロード履歴を保存し、次回起動時に引き継ぐため。

**identity が必要な理由**
Google ログインの認可フローを完了するため。拡張機能は Chrome 標準の認可ウィンドウで Google のログインページを開き、Chrome が拡張機能用に発行する固定のコールバックアドレスで結果を受け取ります。`identity` 権限は、この認可ウィンドウを開きコールバックアドレスを取得するために必要です。

**downloads が必要な理由**
ダウンロードしたファイルをローカルディスクに書き込むため。直接ファイルとバックグラウンド処理で生成したメディアは Chrome のダウンロードマネージャーが保存し、この権限でダウンロードを開始し状態を取得します。

**offscreen が必要な理由**
バックグラウンドで DASH/HLS の取得・結合、アダプティブメディアの切り抜き、MP3 のトランスコードを行う offscreen ドキュメントを作成するため。元のページやポップアップを開いたままにする必要はありません。一時出力はブラウザのローカルストレージ（OPFS）に保存し、ダウンロードへの引き渡し後に削除します。

**notifications が必要な理由**
ダウンロードの成功・失敗をシステム通知で知らせ、ポップアップを閉じていても結果を確認できるようにするため。

**ウェブサイトアクセス権限が必要な理由**
- `https://vimeo.com/*`、`https://www.vimeo.com/*`、`https://player.vimeo.com/*`
  対応するトップレベルの Vimeo 動画ページにパネルを挿入し、プレーヤー情報（動画 ID、画質、音声トラック、字幕、カバー画像 URL）を取得するため。player フレームの補助スクリプトは動画の識別情報だけを提供します。
- `https://*.vimeocdn.com/*`
  プレーヤー情報が指す Vimeo メディア CDN のファイル、プレイリスト、メディアセグメントを取得するため。

## 한국어

**storage가 필요한 이유**
확장 프로그램의 설정(원격 설정의 로컬 캐시), UI 언어, 로그인 상태, 로컬 다운로드 기록을 저장해 다음 실행 시 이어 쓰기 위함.

**identity가 필요한 이유**
Google 로그인 인증 흐름을 완료하기 위함. 확장 프로그램은 Chrome 자체 인증 창으로 Google 로그인 페이지를 열고, Chrome이 확장 프로그램용으로 발급하는 고정 콜백 주소에서 결과를 받습니다. `identity` 권한은 이 인증 창을 열고 콜백 주소를 얻기 위해 필요합니다.

**downloads가 필요한 이유**
다운로드한 파일을 로컬 디스크에 기록하기 위함. 직접 파일과 백그라운드 처리로 생성한 미디어는 Chrome 다운로드 관리자가 저장하며, 이 권한으로 다운로드를 시작하고 상태를 읽습니다.

**offscreen이 필요한 이유**
백그라운드에서 DASH/HLS 가져오기 및 합치기, 적응형 미디어 자르기, MP3 트랜스코딩을 수행할 offscreen 문서를 만들기 위함. 원본 페이지나 팝업을 열어 둘 필요가 없습니다. 임시 출력은 브라우저 로컬 저장소(OPFS)에 저장하고 다운로드에 전달한 뒤 정리합니다.

**notifications가 필요한 이유**
다운로드 성공 또는 실패를 시스템 알림으로 알려 팝업이 닫혀 있어도 결과를 확인하기 위함.

**웹사이트 액세스 권한이 필요한 이유**
- `https://vimeo.com/*`, `https://www.vimeo.com/*`, `https://player.vimeo.com/*`
  지원되는 최상위 Vimeo 동영상 페이지에 패널을 삽입하고 플레이어 정보(동영상 ID, 화질, 오디오 트랙, 자막, 커버 이미지 URL)를 가져오기 위함. player 프레임의 보조 스크립트는 동영상 식별 정보만 제공합니다.
- `https://*.vimeocdn.com/*`
  플레이어 정보가 가리키는 Vimeo 미디어 CDN의 파일, 재생 목록, 미디어 세그먼트를 가져오기 위함.
