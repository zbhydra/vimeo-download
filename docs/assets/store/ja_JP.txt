Vimeo Video Downloader — Vimeo の動画・音声・カバー画像を Chrome に保存

Vimeo を視聴している方向けの Chrome 拡張機能です。再生中の動画をローカルに保存でき、ページ上に動画・音声・カバー画像の 3 行パネルを表示します。


これは何か

Vimeo Video Downloader は、Vimeo のページ（vimeo.com、www.vimeo.com、player.vimeo.com）で動作する Chrome 拡張機能です。ページ上の Vimeo プレーヤーがすでに読み込んでいる再生情報を読み取り、動画・音声トラック・カバー画像のダウンロードボタンに変換します。

Vimeo クライアントでも、ボットでも、単体のダウンローダーでもありません。すでに開いている Vimeo ページの中で完結して動作し、そのページが現在再生している動画だけを扱えます。


こんな場面に向いています

次のいずれかに当てはまるなら、この拡張機能が役立ちます。

1. 視聴中の動画をローカルに保存したい
   ブラウザでは問題なく再生できるのに、ページに保存の入口がない。

2. 既定ではなく特定の画質がほしい
   プレーヤーがたまたま配信しているものではなく、720p や 1080p のファイル、あるいは音声トラックだけがほしい。

3. カバー画像がほしい
   動画のサムネイル画像を単体のファイルとして保存したい。

4. 何度もクリックせずに複数まとめて処理したい
   ポップアップの一覧で複数項目にチェックを入れて、まとめてキューに入れたい。

どれも当てはまらない場合、ブラウザ標準の保存機能で足りるかもしれません。この拡張機能は不要です。


主な機能

### ページ内ダウンロードパネル
Vimeo の動画ページを開くと、動画タイトル付近に小さなパネルが追加され、常に 3 行表示されます。

- Video — 利用できる画質ごとに 1 つのボタン
- Audio — 利用できる音声トラックごとに 1 つのボタン
- Image — カバー画像

その種類のファイルが現在の動画で利用できない場合、その行にはダッシュ記号のプレースホルダーが表示されます。ページを再読み込みせず別の動画へ移動すると、パネルは作り直されます。

### 動画のダウンロード
動画を MP4 ファイルとして保存します。Vimeo プレーヤーがその動画に対して提供している内容に応じて、次のような項目が表示されます。

- 解像度が付いた直接配信の MP4（例:「720p MP4」「1080p MP4」）
- 「1080p HD」と表示されるアダプティブ項目。保存前に映像トラックと音声トラックを 1 つの MP4 に結合します
- その配信方式しか提供されていない動画向けの、フォールバック項目「1080p HLS」
- その動画で利用できる最高画質を自動で選ぶ「Best」ボタン

一覧に出るのは、Vimeo が実際にその動画へ提供している画質だけです。拡張機能が画質をでっち上げたり、拡大したり、トランスコードしたりすることはありません。

### 音声のダウンロード
音声トラックだけを M4A ファイルとして保存します。ボタンには音声ビットレート（例:「128 kbps」）が表示され、最高ビットレートを自動で選ぶ「Best Audio」ボタンもあります。

### カバー画像のダウンロード
動画のカバー画像を JPEG ファイルとして保存します。

### ポップアップのリソース一覧
拡張機能のアイコンをクリックすると、現在のタブで解析済みのすべてのダウンロード可能項目が表示されます。

- 種類ごとにグループ化し、動画・音声・画像の件数を表示
- 単一項目、チェックした項目、一覧のすべてをダウンロード
- リアルタイムの進捗、転送速度、項目ごとの状態
- 一覧のクリアとページの再スキャン

### 一括ダウンロード
ダウンロードは 1 つのキューを通ります。ファイルごとに新しいタブを開くことなく、複数項目をまとめてキューに入れられます。ファイルは順番にディスクへ書き込まれます。

### 大きなファイル
Chrome 自身が取得できるファイルは Chrome 標準のダウンロードマネージャーに渡されるため、転送はページが開いているかどうかに依存しません。アダプティブ（セグメント分割）動画はページ内で結合する必要があり、この経路にはメモリ予算があります。既定では 768 MB を超えるセグメント分割動画はダウンロード対象として提示されず、実行中に予算を超えた場合も中断されます。

この予算は拡張機能のリモート設定で変更できるため、新しいバージョンを配信せずに引き上げたり下げたりできます。

### Vimeo のページ挙動に合わせた設計
Vimeo はシングルページアプリケーションです。拡張機能は動画間の遷移を監視し、前の動画の古い項目ではなく、実際に表示している動画のパネルを作り直します。

### プレーヤー自身のダウンロードボタンには依存しない
拡張機能が Vimeo プレーヤー内の何かを代わりにクリックすることはありません。プレーヤーがすでにブラウザに読み込んだ再生設定を読み取り、独自の保存ボタンを提供します。


使い方

1. Chrome ウェブストアから拡張機能をインストールします
2. すぐ開けるようにアイコンをツールバーにピン留めします
3. vimeo.com または player.vimeo.com の任意の動画ページを開いて再生を始めます
4. 動画タイトルの横に、Video・Audio・Image の 3 行からなるダウンロードパネルが表示されます
5. 希望の画質をクリックするか、拡張機能のアイコンを開いて一覧全体を表示します
6. ファイルはブラウザによってローカルディスクへ書き込まれます

ログインは任意です。ログインは 1 日のダウンロード上限とサブスクリプション状態にのみ使われ、ページを読み取るために必要ではありません。


できること、できないこと

できること:
- ご自身のブラウザで再生できる vimeo.com、www.vimeo.com、player.vimeo.com の動画
- 既定のストリームではなく、特定の画質や音声トラックの選択
- カバー画像の保存
- 同じページから複数項目をまとめてキューに入れること

できないこと:
- 非公開・パスワード保護・有料など、アクセスが制限された Vimeo 動画のダウンロード。これらは Vimeo 自身のアクセス制御であり、拡張機能はそれを回避できませんし、回避しません。プレーヤーがご自身のブラウザで再生できない動画は、拡張機能でも保存できません
- DRM の解除や回避
- ページがまだ読み込んでいない情報の取得
- Vimeo 以外のサイトでの動作
- Vimeo のデスクトップアプリ・モバイルアプリでの動作（これはブラウザ拡張機能です）
- バックグラウンドでのクロールやスクレイピング


よくある質問

Q: 拡張機能のアカウント登録は必要ですか？
A: いいえ。ログインしなくてもダウンロードできます。ログインは任意で、1 日のダウンロード上限とサブスクリプション状態にのみ影響します。

Q: 非公開・パスワード保護・有料の Vimeo 動画をダウンロードできますか？
A: できません。これらの制限は Vimeo が適用しているもので、この拡張機能によるものではありません。拡張機能は、Vimeo がすでにブラウザへ配信し、あなたが再生できる動画の再生情報しか見ることができません。解除・推測・回避は一切行いません。

Q: どの画質が取得できますか？
A: Vimeo がその動画に対して実際に配信しているものです。一般的なページでは複数の直接配信 MP4、あるいはアダプティブ配信が提供され、利用可能な最高画質は常に「Best」として表示されます。一覧にこれ以上の解像度がない場合、Vimeo があなたのブラウザへ配信していないということです。

Q: 一部のダウンロードにサイズ制限があるのはなぜですか？
A: Chrome が直接取得できるファイルには、拡張機能による制限はありません。アダプティブ（セグメント分割）動画はページ内で結合する必要がありメモリを消費するため、予算を設けています。予算は拡張機能のリモート設定で変更でき、既定値は 768 MB です。

Q: 拡張機能はデータをどこかへ送信しますか？
A: メディア本体が開発者の運用するサーバーを経由することは一切ありません。動画・音声・画像は Vimeo のサーバーからあなたのブラウザへ、そしてローカルディスクへと流れます。拡張機能が開発者の API にアクセスするのは、ログイン、1 日のダウンロード上限、サブスクリプション状態、および小さなリモート設定ファイルのためだけです。

Q: どのような権限が必要ですか？
A: storage（設定とログイン状態の保存）、identity（Chrome 標準の認証ウィンドウによる Google ログイン）、downloads（ファイルのディスクへの書き込み）、そしてパネルの表示とファイル取得のための Vimeo ページおよび Vimeo メディア CDN へのアクセスです。

Q: 無料ですか？
A: 1 日あたりの無料ダウンロード枠があり、新しいアカウントやデバイスは初日が無制限です。より多い、または無制限のダウンロードが必要な場合は有料の Unlimited プランがあります。一覧は拡張機能の公式サイトの料金ページにあります。

Q: 対応ブラウザは？
A: Chrome、および Edge や Brave などの Chromium ベースのブラウザです。

Q: すべての Vimeo ページで使えますか？
A: vimeo.com、www.vimeo.com、player.vimeo.com の動画ページで使えます。単一の動画を再生しないページ（プロフィール、フィード、検索結果）には、拡張機能が読み取れるものがありません。

Q: 出力されるファイル形式は？
A: 動画は MP4、音声は M4A、カバー画像は JPEG です。


技術情報

- ブラウザ: Chrome、Edge、Brave、その他の Chromium ベースブラウザ
- Manifest V3
- ホスト権限: vimeo.com、www.vimeo.com、player.vimeo.com、および Vimeo のメディア CDN ホスト
- ダウンロード: 直接ファイルは Chrome 標準のダウンロードマネージャー経由、セグメント分割動画はページ内で結合
- アダプティブ動画のメモリ予算: 既定 768 MB、リモートで設定可能
- UI 言語: 14 ロケール

インストール

すでに視聴できる Vimeo 動画をローカルに保存したい方は、Chrome ウェブストアから Vimeo Video Downloader をインストールしてください。拡張機能は Vimeo のページでのみ動作します。
