Vimeo Downloader — сохраняйте видео, аудио, субтитры и обложки Vimeo в Chrome

Расширение Chrome для тех, кто смотрит Vimeo и хочет локальную копию видео, с панелью на странице для скачивания видео, аудио, субтитров и обложки.


ЧТО ЭТО

Vimeo Downloader — расширение Chrome для поддерживаемых видеостраниц Vimeo (vimeo.com, www.vimeo.com и player.vimeo.com). Оно анализирует данные воспроизведения плеера и предлагает кнопки скачивания видео, аудио, субтитров и обложки.

Это не клиент Vimeo, не бот и не отдельный загрузчик. Расширение обнаруживает ресурсы на поддерживаемых страницах Vimeo и выполняет скачивания в фоне браузера.


КОМУ ПОДХОДИТ

Вы, скорее всего, попали на эту страницу, потому что хотите одно из следующего:

1. Локальную копию видео, которое смотрите
   Видео воспроизводится в браузере, но на странице нет возможности его сохранить.

2. Определённое качество вместо качества по умолчанию
   Вам нужен файл 720p или 1080p либо только аудиодорожка, а не то, что плеер транслирует в данный момент.

3. Обложку
   Вы хотите сохранить обложку видео отдельным файлом.

4. Несколько файлов в очереди
   Вы хотите добавлять элементы по одному во всплывающем окне и скачивать их по порядку.

Если ничего из этого не подходит, возможностей сохранения самого браузера, скорее всего, достаточно и это расширение вам не нужно.


ОСНОВНЫЕ ВОЗМОЖНОСТИ

### Панель скачивания на странице
На поддерживаемых видеостраницах Vimeo расширение добавляет возле заголовка или элементов управления панель с четырьмя строками:

- Video — по кнопке на каждое доступное качество видео
- Audio — по кнопке на каждую доступную аудиодорожку
- Subtitle — доступные дорожки субтитров
- Image — обложка

Если файл этого типа недоступен, строка показывает неактивный элемент. При переходе на другое видео без перезагрузки страницы панель строится заново.

### Скачивание видео
Видео сохраняется файлом MP4. В зависимости от того, что плеер Vimeo предоставляет для этого видео, вы увидите:

- Прямые MP4-пункты с указанием разрешения, например «720p MP4» или «1080p MP4»
- Адаптивные пункты с пометкой «1080p HD», где видеодорожка и аудиодорожка объединяются в один MP4 перед сохранением
- Резервный пункт «1080p HLS» для видео, которые предлагают только такой способ доставки
- Кнопку «Best», которая выбирает наивысшее доступное качество для этого видео

В список попадают только найденные качества. Видео объединяется без перекодирования и увеличения разрешения; аудиовыход MP3 использует перекодирование.

### Скачивание аудио
Аудиодорожка сохраняется как M4A; во всплывающем окне можно выбрать MP3 с перекодированием. Кнопки показывают битрейт (например «128 kbps»), а «Best Audio» выбирает максимальный доступный.

### Субтитры, обрезка и настройки
Доступные субтитры сохраняются как VTT. Во всплывающем окне можно обрезать адаптивное видео и аудио; видео не перекодируется, точность определяется ключевыми кадрами. Прогрессивный MP4 сохраняется целиком. Обрезка всё равно скачивает полный источник. Настройки включают подпапку, шаблон имени файла и язык. Локальную историю успешных и неудачных скачиваний можно экспортировать в CSV.

### Скачивание обложки
Обложка видео сохраняется файлом JPEG.

### Список ресурсов во всплывающем окне
Нажмите на значок расширения, чтобы увидеть все доступные для скачивания элементы, найденные на текущей вкладке:

- Строки для видео, аудио, субтитров и изображений; прогрессивный MP4 находится в отдельной строке прямого скачивания
- Выбор варианта и скачивание одного элемента из его строки
- Прогресс в реальном времени, скорость передачи и состояние каждого элемента


### Очередь скачиваний
Добавляйте элементы по одному в общую для всех вкладок очередь FIFO. Они сохраняются по порядку; переход на другую страницу или закрытие исходной вкладки сами по себе не прерывают скачивания.

### Большие файлы
Прямые файлы скачивает менеджер загрузок Chrome. Адаптивные медиа DASH/HLS собираются в offscreen-документе, временный результат записывается в локальное хранилище браузера (OPFS). Входные данные по-прежнему занимают память: бюджет по умолчанию 768 MiB. Заведомо слишком большие элементы не предлагаются, а при превышении бюджета скачивание останавливается. Потоковый ввод неограниченного размера не поддерживается.

Этот бюджет настраивается через удалённую конфигурацию расширения, поэтому его можно поднять или опустить без выпуска новой версии.

### Рассчитано на поведение страниц Vimeo
Vimeo — это одностраничное приложение. Расширение отслеживает переходы между видео и перестраивает панель для того видео, на котором вы действительно находитесь, вместо показа устаревших пунктов предыдущего.

### Не зависит от собственной кнопки скачивания плеера
Расширение ничего не нажимает за вас в плеере Vimeo. Оно читает конфигурацию воспроизведения, которую плеер уже загрузил в ваш браузер, и предлагает собственные кнопки сохранения.


КАК ЭТО РАБОТАЕТ

1. Установите расширение из Chrome Web Store
2. Закрепите значок на панели инструментов для быстрого доступа
3. Откройте поддерживаемую видеостраницу на vimeo.com или player.vimeo.com и запустите воспроизведение
4. Появится панель со строками Video, Audio, Subtitle и Image
5. Нажмите нужное качество или откройте значок расширения, чтобы увидеть полный список
6. Файл записывается браузером на ваш локальный диск

Вход необязателен. Он нужен только для суточного лимита скачиваний и статуса подписки; для чтения страницы он не требуется.

Подходит для:
- Поддерживаемые видеостраницы верхнего уровня на vimeo.com, www.vimeo.com и player.vimeo.com; возможность воспроизведения не гарантирует скачивание

- Не удаляет и не обходит DRM

- Не работает на сайтах, кроме Vimeo
- Не работает в настольном или мобильном приложении Vimeo — это только расширение браузера
- Не выполняет никакого фонового обхода или сбора данных


ЧАСТЫЕ ВОПРОСЫ

В: Нужен ли аккаунт для использования расширения?
О: Нет. Скачивать можно без входа. Вход необязателен и влияет только на суточный лимит скачиваний и статус подписки.

В: Можно ли скачать закрытые, защищённые паролем или платные видео Vimeo?
О: Поддержка не гарантируется. Расширение использует доступные браузеру данные воспроизведения и не разблокирует и не обходит контроль доступа Vimeo.

В: Какие качества можно получить?
О: Поддерживаемые качества, которые расширение может найти для видео. «Best» выбирает максимальное доступное. Отсутствие разрешения может зависеть от источника, поддержки формата или бюджета адаптивного ввода.

В: Почему у некоторых скачиваний есть ограничение по размеру?
О: Прямые файлы скачивает менеджер Chrome. Адаптивный ввод занимает память даже при выводе в OPFS; удалённо настраиваемый бюджет по умолчанию составляет 768 MiB. Обрезка не уменьшает размер скачивания полного источника.

В: Расширение куда-нибудь отправляет мои данные?
О: Медиафайлы не проходят через серверы разработчиков. Видео, аудио, субтитры и изображения идут от Vimeo в браузер и на локальный диск. Сервисы разработчика также используются для аккаунтов, лимитов, подписок, удалённых настроек и отчётов об использовании и ошибках.

В: Какие разрешения нужны расширению?
О: storage (настройки, вход и локальная история), identity (вход через Google), downloads (сохранение файлов и чтение статуса), offscreen (фоновая обработка медиа), notifications (успешное или неудачное скачивание) и доступ к Vimeo и его медиа-CDN.

В: Расширение бесплатное?
О: Есть бесплатный суточный лимит скачиваний, а новый аккаунт или устройство начинает с неограниченного первого дня. Доступен платный план Unlimited для большего или неограниченного числа скачиваний в день. Полный список — на странице тарифов сайта расширения.

В: Какие браузеры поддерживаются?
О: Chrome и другие браузеры на базе Chromium, например Edge и Brave.

В: Работает ли расширение на всех страницах Vimeo?
О: Поддерживается ограниченный набор видеостраниц верхнего уровня на vimeo.com, www.vimeo.com и player.vimeo.com. Поддержка встроенных плееров на сторонних сайтах и всех закрытых страниц или прямых эфиров не гарантируется.

В: Какие форматы файлов получаются?
О: MP4 для видео, M4A или MP3 для аудио, VTT для субтитров, JPEG для обложки.
