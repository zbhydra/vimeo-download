Vimeo Video Downloader — сохраняйте видео, аудио и обложки Vimeo в Chrome

Расширение Chrome для тех, кто смотрит Vimeo и хочет сохранить локальную копию видео, которое уже воспроизводится, с панелью прямо на странице для скачивания видео, аудио и обложки.


ЧТО ЭТО

Vimeo Video Downloader — расширение Chrome для страниц Vimeo (vimeo.com, www.vimeo.com и player.vimeo.com). Оно читает информацию о воспроизведении, которую плеер Vimeo на странице уже загрузил, и превращает её в кнопки скачивания видео, его аудиодорожки и обложки.

Это не клиент Vimeo, не бот и не отдельный загрузчик. Расширение работает полностью внутри уже открытой страницы Vimeo и взаимодействует только с тем видео, которое эта страница воспроизводит в данный момент.


КОМУ ПОДХОДИТ

Вы, скорее всего, попали на эту страницу, потому что хотите одно из следующего:

1. Локальную копию видео, которое смотрите
   Видео воспроизводится в браузере, но на странице нет возможности его сохранить.

2. Определённое качество вместо качества по умолчанию
   Вам нужен файл 720p или 1080p либо только аудиодорожка, а не то, что плеер транслирует в данный момент.

3. Обложку
   Вы хотите сохранить обложку видео отдельным файлом.

4. Несколько файлов без повторения одних и тех же кликов
   Вы хотите отметить несколько пунктов в списке всплывающего окна и поставить их в очередь за один раз.

Если ничего из этого не подходит, возможностей сохранения самого браузера, скорее всего, достаточно и это расширение вам не нужно.


ОСНОВНЫЕ ВОЗМОЖНОСТИ

### Панель скачивания на странице
Когда открывается страница видео Vimeo, расширение добавляет рядом с заголовком видео небольшую панель с тремя строками:

- Video — по кнопке на каждое доступное качество видео
- Audio — по кнопке на каждую доступную аудиодорожку
- Image — обложка

Если файл такого типа для текущего видео недоступен, в строке вместо кнопки отображается прочерк. При переходе на другое видео без перезагрузки страницы панель строится заново.

### Скачивание видео
Видео сохраняется файлом MP4. В зависимости от того, что плеер Vimeo предоставляет для этого видео, вы увидите:

- Прямые MP4-пункты с указанием разрешения, например «720p MP4» или «1080p MP4»
- Адаптивные пункты с пометкой «1080p HD», где видеодорожка и аудиодорожка объединяются в один MP4 перед сохранением
- Резервный пункт «1080p HLS» для видео, которые предлагают только такой способ доставки
- Кнопку «Best», которая выбирает наивысшее доступное качество для этого видео

В список попадают только те качества, которые Vimeo действительно отдаёт для этого видео. Расширение ничего не выдумывает, не увеличивает и не перекодирует.

### Скачивание аудио
Аудиодорожка сохраняется отдельно файлом M4A. На кнопках указан битрейт аудио (например, «128 kbps»), плюс есть кнопка «Best Audio», выбирающая максимальный доступный битрейт.

### Скачивание обложки
Обложка видео сохраняется файлом JPEG.

### Список ресурсов во всплывающем окне
Нажмите на значок расширения, чтобы увидеть все доступные для скачивания элементы, найденные на текущей вкладке:

- Сгруппированы по типу, с количеством видео, аудио и изображений
- Скачивание одного элемента, отмеченных элементов или всего списка
- Прогресс в реальном времени, скорость передачи и состояние каждого элемента
- Очистка списка и повторное сканирование страницы

### Пакетное скачивание
Скачивания проходят через одну очередь, поэтому можно поставить в очередь несколько элементов сразу, не открывая новую вкладку для каждого файла. Файлы записываются на диск по очереди.

### Большие файлы
Файлы, которые Chrome может получить сам, передаются собственному менеджеру загрузок Chrome, поэтому передача продолжается независимо от того, открыта ли ещё страница. Адаптивные (сегментированные) видео приходится собирать внутри страницы, и у этого пути есть бюджет памяти: по умолчанию сегментированное видео размером более 768 МБ не предлагается к скачиванию, а начатое скачивание прерывается при превышении этого бюджета.

Этот бюджет настраивается через удалённую конфигурацию расширения, поэтому его можно поднять или опустить без выпуска новой версии.

### Рассчитано на поведение страниц Vimeo
Vimeo — это одностраничное приложение. Расширение отслеживает переходы между видео и перестраивает панель для того видео, на котором вы действительно находитесь, вместо показа устаревших пунктов предыдущего.

### Не зависит от собственной кнопки скачивания плеера
Расширение ничего не нажимает за вас в плеере Vimeo. Оно читает конфигурацию воспроизведения, которую плеер уже загрузил в ваш браузер, и предлагает собственные кнопки сохранения.


КАК ЭТО РАБОТАЕТ

1. Установите расширение из Chrome Web Store
2. Закрепите значок на панели инструментов для быстрого доступа
3. Откройте любую страницу видео на vimeo.com или player.vimeo.com и запустите воспроизведение
4. Рядом с заголовком видео появится панель скачивания со строками Video, Audio и Image
5. Нажмите нужное качество или откройте значок расширения, чтобы увидеть полный список
6. Файл записывается браузером на ваш локальный диск

Вход необязателен. Он нужен только для суточного лимита скачиваний и статуса подписки; для чтения страницы он не требуется.


ДЛЯ ЧЕГО ПОДХОДИТ И ЧЕГО НЕ ДЕЛАЕТ

Подходит для:
- Видео, которые воспроизводятся в вашем браузере на vimeo.com, www.vimeo.com и player.vimeo.com
- Выбора конкретного качества или аудиодорожки вместо потока по умолчанию
- Сохранения обложки
- Постановки в очередь нескольких элементов с одной страницы

Не делает:
- Не скачивает закрытые, защищённые паролем, платные или иным образом ограниченные по доступу видео Vimeo. Это собственные средства контроля доступа Vimeo, и расширение не может и не пытается их обходить: если плеер не может воспроизвести видео в вашем браузере, расширение тоже не сможет его сохранить
- Не удаляет и не обходит DRM
- Не читает информацию, которую страница ещё не загрузила
- Не работает на сайтах, кроме Vimeo
- Не работает в настольном или мобильном приложении Vimeo — это только расширение браузера
- Не выполняет никакого фонового обхода или сбора данных


ЧАСТЫЕ ВОПРОСЫ

В: Нужен ли аккаунт для использования расширения?
О: Нет. Скачивать можно без входа. Вход необязателен и влияет только на суточный лимит скачиваний и статус подписки.

В: Можно ли скачать закрытые, защищённые паролем или платные видео Vimeo?
О: Нет. Эти ограничения применяет Vimeo, а не это расширение. Расширение видит только ту информацию о воспроизведении, которую Vimeo уже передал вашему браузеру для видео, которое вы можете воспроизвести. Оно ничего не разблокирует, не угадывает и не обходит.

В: Какие качества можно получить?
О: Те, которые Vimeo отдаёт для конкретного видео. Обычные страницы предлагают несколько прямых MP4-разрешений и/или адаптивный поток, а самый высокий доступный вариант всегда предлагается как «Best». Если более высокого разрешения нет в списке, значит Vimeo не отдаёт его вашему браузеру.

В: Почему у некоторых скачиваний есть ограничение по размеру?
О: Для файлов, которые Chrome может получить напрямую, расширение никаких ограничений не добавляет. Адаптивные (сегментированные) видео приходится объединять внутри страницы, что расходует память, поэтому применяется бюджет. Он настраивается через удалённую конфигурацию расширения и по умолчанию составляет 768 МБ.

В: Расширение куда-нибудь отправляет мои данные?
О: Сами медиафайлы никогда не проходят через серверы, которыми управляют разработчики. Видео, аудио и изображения идут с серверов Vimeo в ваш браузер, а затем на ваш локальный диск. Расширение обращается к API разработчиков только для входа, суточного лимита скачиваний, статуса подписки и небольшого файла удалённых настроек.

В: Какие разрешения нужны расширению?
О: storage (сохранение ваших настроек и состояния входа), identity (вход через Google в собственном окне авторизации Chrome), downloads (запись файлов на ваш диск) и доступ к страницам Vimeo и медиа-CDN Vimeo, чтобы показывать панель и получать файлы.

В: Расширение бесплатное?
О: Есть бесплатный суточный лимит скачиваний, а новый аккаунт или устройство начинает с неограниченного первого дня. Доступен платный план Unlimited для большего или неограниченного числа скачиваний в день. Полный список — на странице тарифов сайта расширения.

В: Какие браузеры поддерживаются?
О: Chrome и другие браузеры на базе Chromium, например Edge и Brave.

В: Работает ли расширение на всех страницах Vimeo?
О: Работает на страницах видео на vimeo.com, www.vimeo.com и player.vimeo.com. На страницах, которые не воспроизводят отдельное видео (профили, ленты, результаты поиска), расширению нечего читать.

В: Какие форматы файлов получаются?
О: MP4 для видео, M4A для аудио, JPEG для обложки.
