Vimeo Video Downloader — Vimeo 동영상, 오디오, 자막, 커버 이미지를 Chrome에 저장

Vimeo를 시청하는 사용자를 위한 Chrome 확장 프로그램입니다. 보고 있는 동영상을 로컬에 저장하고, 페이지에 동영상·오디오·자막·커버 이미지 4행 패널을 표시합니다.


무엇인가요

Vimeo Video Downloader는 지원되는 Vimeo 동영상 페이지(vimeo.com, www.vimeo.com, player.vimeo.com)에서 동작하는 Chrome 확장 프로그램입니다. 플레이어의 재생 정보를 분석해 동영상, 오디오, 자막, 커버 이미지 다운로드 버튼을 제공합니다.

Vimeo 클라이언트도, 봇도, 독립형 다운로더도 아닙니다. 지원되는 Vimeo 페이지에서 리소스를 감지하고 다운로드는 브라우저 백그라운드에서 실행합니다.


이런 경우에 적합합니다

다음 중 하나에 해당한다면 이 확장 프로그램이 도움이 됩니다.

1. 보고 있는 동영상을 로컬에 저장하고 싶다
   브라우저에서는 잘 재생되는데 페이지에 저장할 방법이 없다.

2. 기본이 아닌 특정 화질을 원한다
   플레이어가 마침 스트리밍하는 화질이 아니라 720p나 1080p 파일, 또는 오디오 트랙만 원한다.

3. 커버 이미지를 원한다
   동영상의 대표 이미지를 별도 파일로 저장하고 싶다.

4. 여러 파일을 대기열에서 순서대로 처리하고 싶다
   팝업에서 항목을 하나씩 추가해 순서대로 다운로드하고 싶다.

해당하는 항목이 없다면 브라우저 기본 저장 기능으로 충분할 수 있으며, 이 확장 프로그램은 필요하지 않습니다.


주요 기능

### 페이지 내 다운로드 패널
지원되는 Vimeo 동영상 페이지의 제목이나 작업 영역 근처에 4행 패널을 추가합니다.

- Video — 사용 가능한 화질마다 버튼 하나
- Audio — 사용 가능한 오디오 트랙마다 버튼 하나
- Subtitle — 사용 가능한 자막 트랙
- Image — 커버 이미지

해당 종류의 파일을 사용할 수 없으면 비활성 자리 표시자가 나옵니다. 페이지를 새로 고치지 않고 다른 동영상으로 이동하면 패널이 다시 만들어집니다.

### 동영상 다운로드
동영상을 MP4 파일로 저장합니다. Vimeo 플레이어가 해당 동영상에 제공하는 내용에 따라 다음 항목이 표시될 수 있습니다.

- 해상도가 붙은 직접 전송 MP4 항목(예: "720p MP4", "1080p MP4")
- "1080p HD"로 표시되는 적응형 항목. 저장 전에 비디오 트랙과 오디오 트랙을 하나의 MP4로 합칩니다
- 해당 전송 방식만 제공되는 동영상을 위한 대체 항목 "1080p HLS"
- 해당 동영상에서 사용 가능한 최고 화질을 자동으로 고르는 "Best" 버튼

분석된 화질만 표시됩니다. 동영상은 트랜스코딩이나 업스케일 없이 합치며, MP3 오디오 출력은 트랜스코딩합니다.

### 오디오 다운로드
오디오 트랙을 M4A로 저장하거나 팝업에서 MP3를 선택해 트랜스코딩할 수 있습니다. 버튼에는 비트레이트(예: "128 kbps")가 표시되고, "Best Audio"는 가장 높은 비트레이트를 고릅니다.

### 자막, 자르기 및 설정
사용 가능한 자막을 VTT로 저장합니다. 팝업에서 적응형 동영상과 오디오를 자를 수 있으며, 동영상은 트랜스코딩 없이 키프레임 단위로 자릅니다. 직접 전송 MP4는 전체 동영상을 저장합니다. 자르기도 전체 원본을 다운로드합니다. 저장 하위 폴더, 파일명 템플릿, UI 언어를 설정할 수 있고, 성공·실패한 다운로드의 로컬 기록을 CSV로 내보낼 수 있습니다.

### 커버 이미지 다운로드
동영상 커버 이미지를 JPEG 파일로 저장합니다.

### 팝업 리소스 목록
확장 프로그램 아이콘을 클릭하면 현재 탭에서 확인된 모든 다운로드 가능 항목을 볼 수 있습니다.

- 동영상, 오디오, 자막, 이미지 리소스 행과 별도의 직접 전송 MP4 다운로드 행
- 옵션을 선택하고 해당 행에서 한 항목씩 다운로드
- 실시간 진행률, 전송 속도, 항목별 상태


### 다운로드 대기열
항목을 하나씩 모든 탭이 공유하는 전역 FIFO 대기열에 추가합니다. 파일은 순서대로 저장되며 페이지 이동이나 원본 탭 닫기 자체로 다운로드가 중단되지는 않습니다.

### 큰 파일
직접 파일은 Chrome 다운로드 관리자를 사용합니다. 적응형 DASH/HLS 미디어는 offscreen 문서에서 합치고 임시 출력을 브라우저 로컬 저장소(OPFS)에 씁니다. 입력은 여전히 메모리를 사용하며 기본 예산은 768 MiB입니다. 초과가 확인된 항목은 제공하지 않고 실행 중 초과하면 중단합니다. 무제한 크기의 스트리밍 입력은 지원하지 않습니다.

이 예산은 확장 프로그램의 원격 설정으로 조정할 수 있어 새 버전을 배포하지 않고도 올리거나 내릴 수 있습니다.

### Vimeo 페이지 동작에 맞춘 설계
Vimeo는 단일 페이지 애플리케이션입니다. 확장 프로그램은 동영상 간 이동을 감시하고, 이전 동영상의 오래된 항목이 아니라 실제로 보고 있는 동영상의 패널을 다시 만듭니다.

### 플레이어 자체 다운로드 버튼에 의존하지 않음
확장 프로그램이 Vimeo 플레이어 안의 무언가를 대신 클릭하지 않습니다. 플레이어가 이미 브라우저에 불러온 재생 설정을 읽어 자체 저장 버튼을 제공합니다.


사용 방법

1. Chrome 웹 스토어에서 확장 프로그램을 설치합니다
2. 빠르게 열 수 있도록 아이콘을 도구 모음에 고정합니다
3. vimeo.com 또는 player.vimeo.com의 지원되는 동영상 페이지를 열고 재생합니다
4. Video, Audio, Subtitle, Image 4행 다운로드 패널이 나타납니다
5. 원하는 화질을 클릭하거나 확장 프로그램 아이콘을 열어 전체 목록을 봅니다
6. 파일은 브라우저가 로컬 디스크에 기록합니다

로그인은 선택 사항입니다. 로그인은 일일 다운로드 한도와 구독 상태에만 사용되며, 페이지를 읽는 데에는 필요하지 않습니다.


할 수 있는 것과 하지 않는 것

할 수 있는 것:
- vimeo.com, www.vimeo.com, player.vimeo.com의 지원되는 최상위 동영상 페이지. 재생 가능하다고 다운로드 가능한 리소스가 보장되지는 않습니다
- 기본 스트림이 아닌 특정 화질이나 오디오 트랙 선택
- 커버 이미지 저장
- 같은 페이지에서 여러 항목을 대기열에 넣기

하지 않는 것:
- 접근 제어 우회. 비공개, 비밀번호 보호, 유료 동영상은 재생되더라도 지원을 보장하지 않습니다
- DRM 제거 또는 우회
- 모든 HLS 형식 지원. MPEG-TS, 전체 라이브 녹화, 외부 오디오/자막 트랙 및 인식되지 않은 암호화는 지원하지 않습니다
- Vimeo 이외의 사이트에서 동작
- Vimeo 데스크톱 또는 모바일 앱에서 동작 — 이는 브라우저 확장 프로그램입니다
- 백그라운드 크롤링이나 스크래핑


자주 묻는 질문

Q: 확장 프로그램 계정이 필요한가요?
A: 아니요. 로그인하지 않아도 다운로드할 수 있습니다. 로그인은 선택 사항이며 일일 다운로드 한도와 구독 상태에만 영향을 줍니다.

Q: 비공개, 비밀번호 보호, 유료 Vimeo 동영상을 다운로드할 수 있나요?
A: 지원을 보장하지 않습니다. 브라우저가 가져올 수 있는 재생 정보를 사용하며 Vimeo의 접근 제어를 해제하거나 우회하지 않습니다.

Q: 어떤 화질을 받을 수 있나요?
A: 확장 프로그램이 분석할 수 있는 지원 화질입니다. "Best"는 사용 가능한 최고 화질을 선택합니다. 빠진 해상도는 원본, 지원 형식 또는 적응형 입력 예산 때문일 수 있습니다.

Q: 일부 다운로드에 크기 제한이 있는 이유는 무엇인가요?
A: 직접 파일은 Chrome 다운로드 관리자를 사용합니다. 출력이 OPFS에 저장되어도 적응형 입력은 메모리를 사용하므로 원격 설정 가능한 예산(기본 768 MiB)이 적용됩니다. 자르기도 전체 원본 다운로드 크기를 줄이지 않습니다.

Q: 확장 프로그램이 제 데이터를 어딘가로 업로드하나요?
A: 미디어는 개발자 서버를 거치지 않습니다. 동영상, 오디오, 자막, 이미지는 Vimeo에서 브라우저와 로컬 디스크로 이동합니다. 계정 기능, 다운로드 한도, 구독, 원격 설정, 사용 및 오류 보고에는 개발자 서비스를 사용합니다.

Q: 어떤 권한이 필요한가요?
A: storage(설정, 로그인 상태, 로컬 기록), identity(Google 로그인), downloads(파일 저장과 상태 확인), offscreen(백그라운드 미디어 처리), notifications(다운로드 성공 또는 실패 알림), Vimeo와 미디어 CDN 접근 권한입니다.

Q: 무료인가요?
A: 일일 무료 다운로드 한도가 있고, 새 계정이나 기기는 첫날 무제한입니다. 더 많거나 무제한 다운로드가 필요하면 유료 Unlimited 플랜이 있습니다. 전체 목록은 확장 프로그램 공식 사이트의 가격 페이지에 있습니다.

Q: 어떤 브라우저를 지원하나요?
A: Chrome 및 Edge, Brave 등 Chromium 기반 브라우저입니다.

Q: 모든 Vimeo 페이지에서 동작하나요?
A: vimeo.com, www.vimeo.com, player.vimeo.com의 일부 최상위 동영상 페이지를 지원합니다. 타사 사이트의 임베디드 플레이어와 모든 비공개 또는 라이브 페이지는 지원을 보장하지 않습니다.

Q: 어떤 파일 형식이 만들어지나요?
A: 동영상은 MP4, 오디오는 M4A 또는 MP3, 자막은 VTT, 커버 이미지는 JPEG입니다.


기술 정보

- 브라우저: Chrome, Edge, Brave 및 기타 Chromium 기반 브라우저

법적 고지 및 준수

이 확장 프로그램은 독립적으로 개발된 서드파티 도구입니다. Vimeo, Inc.와 제휴, 보증, 연관 관계가 없습니다. Vimeo는 Vimeo, Inc.의 상표입니다.

이 확장 프로그램은 이미 정당한 접근 권한이 있는 콘텐츠를 저장하기 위한 것입니다. 적용되는 저작권법, 현지 법규, 그리고 Vimeo 및 콘텐츠 원저작자의 서비스 약관을 준수할 책임은 사용자에게 있습니다. 저작권이 있는 자료의 재배포, 권리가 없는 콘텐츠의 접근 제어 우회, 그 밖의 허가되지 않은 목적으로 이 확장 프로그램을 사용하지 마세요.

이 확장 프로그램은 브라우저 안에서 로컬로 동작합니다. 개발자는 사용자가 다운로드한 미디어를 수신, 저장, 중계하는 서버를 운영하지 않으며, 확장 프로그램이 저장한 동영상, 오디오, 이미지를 수집하지도 않습니다.
