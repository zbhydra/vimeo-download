Vimeo Video Downloader — Vimeo 동영상, 오디오, 커버 이미지를 Chrome에 저장

Vimeo를 시청하는 사용자를 위한 Chrome 확장 프로그램입니다. 보고 있는 동영상을 로컬에 저장하고, 페이지에 동영상·오디오·커버 이미지 3행 패널을 표시합니다.


무엇인가요

Vimeo Video Downloader는 Vimeo 페이지(vimeo.com, www.vimeo.com, player.vimeo.com)에서 동작하는 Chrome 확장 프로그램입니다. 페이지의 Vimeo 플레이어가 이미 불러온 재생 정보를 읽어 동영상, 오디오 트랙, 커버 이미지의 다운로드 버튼으로 바꿔 줍니다.

Vimeo 클라이언트도, 봇도, 독립형 다운로더도 아닙니다. 이미 열려 있는 Vimeo 페이지 안에서만 동작하며, 그 페이지가 현재 재생 중인 동영상만 다룹니다.


이런 경우에 적합합니다

다음 중 하나에 해당한다면 이 확장 프로그램이 도움이 됩니다.

1. 보고 있는 동영상을 로컬에 저장하고 싶다
   브라우저에서는 잘 재생되는데 페이지에 저장할 방법이 없다.

2. 기본이 아닌 특정 화질을 원한다
   플레이어가 마침 스트리밍하는 화질이 아니라 720p나 1080p 파일, 또는 오디오 트랙만 원한다.

3. 커버 이미지를 원한다
   동영상의 대표 이미지를 별도 파일로 저장하고 싶다.

4. 여러 파일을 반복 클릭 없이 한 번에 처리하고 싶다
   팝업 목록에서 여러 항목을 선택해 한꺼번에 대기열에 넣고 싶다.

해당하는 항목이 없다면 브라우저 기본 저장 기능으로 충분할 수 있으며, 이 확장 프로그램은 필요하지 않습니다.


주요 기능

### 페이지 내 다운로드 패널
Vimeo 동영상 페이지를 열면 동영상 제목 근처에 작은 패널이 추가되고, 항상 세 행이 표시됩니다.

- Video — 사용 가능한 화질마다 버튼 하나
- Audio — 사용 가능한 오디오 트랙마다 버튼 하나
- Image — 커버 이미지

해당 종류의 파일을 현재 동영상에서 사용할 수 없으면 그 행에는 대시 표시만 나옵니다. 페이지를 새로 고치지 않고 다른 동영상으로 이동하면 패널이 다시 만들어집니다.

### 동영상 다운로드
동영상을 MP4 파일로 저장합니다. Vimeo 플레이어가 해당 동영상에 제공하는 내용에 따라 다음 항목이 표시될 수 있습니다.

- 해상도가 붙은 직접 전송 MP4 항목(예: "720p MP4", "1080p MP4")
- "1080p HD"로 표시되는 적응형 항목. 저장 전에 비디오 트랙과 오디오 트랙을 하나의 MP4로 합칩니다
- 해당 전송 방식만 제공되는 동영상을 위한 대체 항목 "1080p HLS"
- 해당 동영상에서 사용 가능한 최고 화질을 자동으로 고르는 "Best" 버튼

목록에는 Vimeo가 실제로 그 동영상에 제공하는 화질만 나옵니다. 확장 프로그램이 화질을 만들어 내거나 업스케일하거나 트랜스코딩하지는 않습니다.

### 오디오 다운로드
오디오 트랙만 M4A 파일로 저장합니다. 버튼에는 오디오 비트레이트(예: "128 kbps")가 표시되며, 최고 비트레이트를 자동으로 고르는 "Best Audio" 버튼도 있습니다.

### 커버 이미지 다운로드
동영상 커버 이미지를 JPEG 파일로 저장합니다.

### 팝업 리소스 목록
확장 프로그램 아이콘을 클릭하면 현재 탭에서 확인된 모든 다운로드 가능 항목을 볼 수 있습니다.

- 유형별로 묶어 동영상, 오디오, 이미지 개수 표시
- 단일 항목, 선택한 항목, 목록 전체 다운로드
- 실시간 진행률, 전송 속도, 항목별 상태
- 목록 비우기 및 페이지 다시 스캔

### 일괄 다운로드
다운로드는 하나의 대기열을 통과하므로 파일마다 새 탭을 열지 않고 여러 항목을 한 번에 넣을 수 있습니다. 파일은 순서대로 디스크에 기록됩니다.

### 큰 파일
Chrome이 직접 가져올 수 있는 파일은 Chrome 자체 다운로드 관리자에 넘기므로 페이지가 열려 있는지와 무관하게 전송이 계속됩니다. 적응형(분할) 동영상은 페이지 안에서 합쳐야 하며, 이 경로에는 메모리 예산이 있습니다. 기본적으로 768 MB를 넘는 분할 동영상은 다운로드 대상으로 제공되지 않고, 실행 중 예산을 넘으면 중단됩니다.

이 예산은 확장 프로그램의 원격 설정으로 조정할 수 있어 새 버전을 배포하지 않고도 올리거나 내릴 수 있습니다.

### Vimeo 페이지 동작에 맞춘 설계
Vimeo는 단일 페이지 애플리케이션입니다. 확장 프로그램은 동영상 간 이동을 감시하고, 이전 동영상의 오래된 항목이 아니라 실제로 보고 있는 동영상의 패널을 다시 만듭니다.

### 플레이어 자체 다운로드 버튼에 의존하지 않음
확장 프로그램이 Vimeo 플레이어 안의 무언가를 대신 클릭하지 않습니다. 플레이어가 이미 브라우저에 불러온 재생 설정을 읽어 자체 저장 버튼을 제공합니다.


사용 방법

1. Chrome 웹 스토어에서 확장 프로그램을 설치합니다
2. 빠르게 열 수 있도록 아이콘을 도구 모음에 고정합니다
3. vimeo.com 또는 player.vimeo.com의 아무 동영상 페이지나 열고 재생을 시작합니다
4. 동영상 제목 옆에 Video, Audio, Image 세 행으로 이루어진 다운로드 패널이 나타납니다
5. 원하는 화질을 클릭하거나 확장 프로그램 아이콘을 열어 전체 목록을 봅니다
6. 파일은 브라우저가 로컬 디스크에 기록합니다

로그인은 선택 사항입니다. 로그인은 일일 다운로드 한도와 구독 상태에만 사용되며, 페이지를 읽는 데에는 필요하지 않습니다.


할 수 있는 것과 하지 않는 것

할 수 있는 것:
- 본인 브라우저에서 재생되는 vimeo.com, www.vimeo.com, player.vimeo.com 동영상
- 기본 스트림이 아닌 특정 화질이나 오디오 트랙 선택
- 커버 이미지 저장
- 같은 페이지에서 여러 항목을 대기열에 넣기

하지 않는 것:
- 비공개, 비밀번호 보호, 유료 등 접근이 제한된 Vimeo 동영상 다운로드. 이는 Vimeo 자체의 접근 제어이며 확장 프로그램은 이를 우회할 수 없고 우회하지도 않습니다. 플레이어가 브라우저에서 재생할 수 없는 동영상은 확장 프로그램도 저장할 수 없습니다
- DRM 제거 또는 우회
- 페이지가 아직 불러오지 않은 정보 읽기
- Vimeo 이외의 사이트에서 동작
- Vimeo 데스크톱 또는 모바일 앱에서 동작 — 이는 브라우저 확장 프로그램입니다
- 백그라운드 크롤링이나 스크래핑


자주 묻는 질문

Q: 확장 프로그램 계정이 필요한가요?
A: 아니요. 로그인하지 않아도 다운로드할 수 있습니다. 로그인은 선택 사항이며 일일 다운로드 한도와 구독 상태에만 영향을 줍니다.

Q: 비공개, 비밀번호 보호, 유료 Vimeo 동영상을 다운로드할 수 있나요?
A: 아니요. 그러한 제한은 Vimeo가 적용하는 것이며 이 확장 프로그램이 적용하는 것이 아닙니다. 확장 프로그램은 Vimeo가 이미 브라우저로 전달했고 재생할 수 있는 동영상의 재생 정보만 볼 수 있습니다. 잠금 해제, 추측, 우회를 하지 않습니다.

Q: 어떤 화질을 받을 수 있나요?
A: Vimeo가 해당 동영상에 실제로 제공하는 화질입니다. 일반적인 페이지는 여러 개의 직접 전송 MP4 또는 적응형 스트림을 제공하며, 사용 가능한 최고 화질은 항상 "Best"로 표시됩니다. 목록에 더 높은 해상도가 없다면 Vimeo가 브라우저에 제공하지 않는 것입니다.

Q: 일부 다운로드에 크기 제한이 있는 이유는 무엇인가요?
A: Chrome이 직접 가져오는 파일에는 확장 프로그램이 제한을 추가하지 않습니다. 적응형(분할) 동영상은 페이지 안에서 합쳐야 하고 메모리를 사용하므로 예산을 둡니다. 예산은 확장 프로그램 원격 설정으로 조정할 수 있으며 기본값은 768 MB입니다.

Q: 확장 프로그램이 제 데이터를 어딘가로 업로드하나요?
A: 미디어 자체는 개발자가 운영하는 어떤 서버도 거치지 않습니다. 동영상, 오디오, 이미지는 Vimeo 서버에서 사용자의 브라우저로, 다시 로컬 디스크로 이동합니다. 확장 프로그램이 개발자 API에 접근하는 경우는 로그인, 일일 다운로드 한도, 구독 상태, 그리고 작은 원격 설정 파일뿐입니다.

Q: 어떤 권한이 필요한가요?
A: storage(설정과 로그인 상태 저장), identity(Chrome 자체 인증 창을 통한 Google 로그인), downloads(파일을 디스크에 기록), 그리고 패널 표시와 파일 가져오기를 위한 Vimeo 페이지 및 Vimeo 미디어 CDN 접근 권한입니다.

Q: 무료인가요?
A: 일일 무료 다운로드 한도가 있고, 새 계정이나 기기는 첫날 무제한입니다. 더 많거나 무제한 다운로드가 필요하면 유료 Unlimited 플랜이 있습니다. 전체 목록은 확장 프로그램 공식 사이트의 가격 페이지에 있습니다.

Q: 어떤 브라우저를 지원하나요?
A: Chrome 및 Edge, Brave 등 Chromium 기반 브라우저입니다.

Q: 모든 Vimeo 페이지에서 동작하나요?
A: vimeo.com, www.vimeo.com, player.vimeo.com의 동영상 페이지에서 동작합니다. 단일 동영상을 재생하지 않는 페이지(프로필, 피드, 검색 결과)에는 확장 프로그램이 읽을 것이 없습니다.

Q: 어떤 파일 형식이 만들어지나요?
A: 동영상은 MP4, 오디오는 M4A, 커버 이미지는 JPEG입니다.

이 확장 프로그램은 독립적으로 개발된 서드파티 도구입니다. Vimeo, Inc.와 제휴, 보증, 연관 관계가 없습니다. Vimeo는 Vimeo, Inc.의 상표입니다.

이 확장 프로그램은 이미 정당한 접근 권한이 있는 콘텐츠를 저장하기 위한 것입니다. 적용되는 저작권법, 현지 법규, 그리고 Vimeo 및 콘텐츠 원저작자의 서비스 약관을 준수할 책임은 사용자에게 있습니다. 저작권이 있는 자료의 재배포, 권리가 없는 콘텐츠의 접근 제어 우회, 그 밖의 허가되지 않은 목적으로 이 확장 프로그램을 사용하지 마세요.

이 확장 프로그램은 브라우저 안에서 로컬로 동작합니다. 개발자는 사용자가 다운로드한 미디어를 수신, 저장, 중계하는 서버를 운영하지 않으며, 확장 프로그램이 저장한 동영상, 오디오, 이미지를 수집하지도 않습니다.
