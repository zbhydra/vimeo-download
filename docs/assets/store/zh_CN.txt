Vimeo Downloader — 在 Chrome 中保存 Vimeo 视频、音频、字幕与封面图

一款面向 Vimeo 观看者的 Chrome 扩展：把你正在观看的视频保存到本地，并在页面上提供视频、音频、字幕、封面图四行下载面板。


这是什么

Vimeo Downloader 是一款运行在支持的 Vimeo 视频页面（vimeo.com、www.vimeo.com、player.vimeo.com）上的 Chrome 扩展。它解析播放器的播放信息，提供视频、音频轨、字幕和封面图的下载按钮。

它不是 Vimeo 客户端、不是机器人、也不是独立下载器。它在支持的 Vimeo 页面上发现资源，下载任务在浏览器后台执行。


适合哪些场景

如果你遇到以下情况之一，这个扩展就是为你准备的：

1. 想把正在看的视频存一份到本地
   视频能在浏览器里正常播放，但页面上没有保存入口。

2. 想指定画质，而不是用默认的
   你想要 720p 或 1080p 那个文件，或者只想要音频轨，而不是播放器碰巧在串流的那一档。

3. 想要封面图
   你想把视频的封面图单独存成一个文件。

4. 想让多个文件排队下载
   你想在弹窗中逐项添加任务，让它们按顺序下载。

如果这些都不符合你的情况，浏览器自带的保存功能可能已经够用，你不需要这个扩展。


核心功能

### 页面内下载面板
打开支持的 Vimeo 视频页时，扩展会在视频标题或操作区附近加一个小面板，固定四行：

- Video — 每个可用画质一个按钮
- Audio — 每个可用音频轨一个按钮
- Subtitle — 可用字幕轨
- Image — 封面图

某一类文件对当前视频不可用时，该行显示禁用占位。不刷新页面切换到另一个视频时，面板会重建。

### 视频下载
把视频保存为 MP4 文件。根据 Vimeo 播放器为该视频提供的内容，你可能会看到：

- 标注分辨率的直连 MP4 条目，例如「720p MP4」「1080p MP4」
- 标注为「1080p HD」的自适应条目，保存前会把视频轨和音频轨合并成一个 MP4
- 标注为「1080p HLS」的兜底条目，用于只提供这种交付方式的视频
- 一个「Best」按钮，自动选该视频可用的最高画质

只会列出解析到的画质。视频合成不转码、不放大；选择 MP3 音频输出时会转码。

### 音频下载
把音频轨单独保存为 M4A 文件，或在弹窗中选择 MP3 转码输出。按钮上标注音频码率（例如「128 kbps」），另有「Best Audio」按钮自动选最高可用码率。

### 字幕、裁剪与下载设置
把可用字幕保存为 VTT。在弹窗中可裁剪自适应视频与音频，视频不转码、按关键帧精度裁剪；直连 MP4 只下载全片。裁剪仍需先下载完整来源，再生成片段。设置支持保存子目录、文件名模板与界面语言。成功与失败的下载记录保存在本地历史中，可导出 CSV。

### 封面图下载
把视频封面图保存为 JPEG 文件。

### 弹窗资源列表
点击扩展图标，可以看到当前标签页已解析出的全部可下载项：

- 提供视频、音频、字幕、图片资源行，直连 MP4 单列为「直接下载」行
- 在资源行选择档位，逐项下载
- 实时进度、传输速度与单项状态

### 下载队列
逐项添加的任务进入跨标签页共享的全局先进先出队列，文件按顺序写入磁盘。切换或关闭来源页面本身不会中断下载。

### 大文件
Chrome 能自行抓取的文件交给 Chrome 下载管理器。自适应 DASH/HLS 媒体在离屏文档中合成，输出临时写入浏览器本地存储（OPFS）。输入仍占用内存，默认预算为 768 MiB：已知超限的条目不提供下载，运行中超限则中止。这不代表支持无限大的流式输入。

这个预算可以通过扩展自带的远端配置调整，无需发布新版本即可调高或调低。

### 针对 Vimeo 页面行为设计
Vimeo 是单页应用。扩展会监听视频之间的跳转，为你当前真正所在的视频重建面板，而不是展示上一个视频的过期条目。

### 不依赖播放器自己的下载按钮
扩展不会替你点击 Vimeo 播放器里的任何东西。它读取播放器已经加载到浏览器里的播放配置，并提供自己的保存按钮。


如何使用

1. 从 Chrome 应用商店安装扩展
2. 把图标固定到工具栏，方便随时打开
3. 打开 vimeo.com 或 player.vimeo.com 上支持的视频页并开始播放
4. 页面会出现下载面板，内含 Video、Audio、Subtitle、Image 四行
5. 点击你想要的画质，或打开扩展图标查看完整列表
6. 文件由浏览器写入你的本地磁盘

登录是可选的。登录只用于每日下载额度和订阅状态，扩展读取页面并不需要登录。


能用在哪里，以及它不做什么

适用于：
- vimeo.com、www.vimeo.com、player.vimeo.com 上支持的顶层视频页；能播放不代表一定能解析出下载资源
- 指定画质或音频轨，而不是默认串流
- 保存封面图
- 在同一个页面上排队下载多项

不做：
- 绕过访问控制。私密、密码保护或付费视频即使能播放，也不保证支持下载
- 移除或绕过 DRM
- 支持所有 HLS 格式：不支持 MPEG-TS、完整直播录制、外置音频或字幕轨及未识别的加密方式
- 在 Vimeo 以外的网站上工作
- 在 Vimeo 桌面端或移动端应用上工作 —— 这只是浏览器扩展
- 任何后台爬取或抓取


常见问题

Q：使用扩展需要账号吗？
A：不需要。不登录也能下载。登录是可选的，只影响每日下载额度和订阅状态。

Q：能下载私密、密码保护或付费的 Vimeo 视频吗？
A：不保证支持。扩展使用浏览器能取得的播放信息，不会解锁或绕过 Vimeo 的访问控制。

Q：能拿到哪些画质？
A：扩展能解析并支持的画质。「Best」选择可用的最高画质。缺少某档分辨率可能与来源、格式支持或自适应输入预算有关。

Q：为什么有些下载有大小限制？
A：直连文件使用 Chrome 下载管理器。自适应输出虽然写入 OPFS，输入仍占内存，因此设置可远端调整的预算，默认 768 MiB。裁剪不会减少完整来源的下载大小。

Q：扩展会把我的数据上传到什么地方吗？
A：媒体文件本身从不经过开发者运营的任何服务器。视频、音频、字幕和图片从 Vimeo 服务器到浏览器与本地磁盘。扩展还会访问开发者服务，用于账号功能、下载额度、订阅、远端设置及使用情况与错误上报。

Q：扩展需要哪些权限？
A：storage（设置、登录态与本地历史）、identity（Google 登录）、downloads（保存文件与读取状态）、offscreen（后台媒体处理）、notifications（下载完成或失败通知），以及 Vimeo 页面和媒体 CDN 的访问权限。

Q：免费吗？
A：有每日免费下载额度，新账号或新设备的第一天不限次数。另有付费的 Unlimited 计划，可获得更高或不限的每日下载次数。完整列表见扩展官网的定价页。

Q：支持哪些浏览器？
A：Chrome 以及其他 Chromium 内核浏览器，例如 Edge 和 Brave。

Q：每个 Vimeo 页面都能用吗？
A：支持 vimeo.com、www.vimeo.com 和 player.vimeo.com 上有限的顶层视频页。不保证支持第三方网站中的嵌入播放器、所有私密页或直播页。

Q：产出什么文件格式？
A：视频为 MP4，音频为 M4A 或 MP3，字幕为 VTT，封面图为 JPEG。


技术说明

- 浏览器：Chrome、Edge、Brave 及其他 Chromium 内核浏览器
- Manifest V3
- 网站存取权限：vimeo.com、www.vimeo.com、player.vimeo.com 以及 Vimeo 的媒体 CDN 主机
- 下载方式：全局先进先出队列；直连文件使用 Chrome 下载管理器，DASH/HLS 在离屏文档中处理
- 自适应输入内存预算：默认 768 MiB，可远端配置；OPFS 仅存储输出
- 界面语言：14 种
