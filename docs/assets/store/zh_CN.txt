Vimeo Video Downloader — 在 Chrome 中保存 Vimeo 视频、音频与封面图

一款面向 Vimeo 观看者的 Chrome 扩展：把你正在观看的视频保存到本地，并在页面上提供视频、音频、封面图三行下载面板。


这是什么

Vimeo Video Downloader 是一款运行在 Vimeo 页面（vimeo.com、www.vimeo.com、player.vimeo.com）上的 Chrome 扩展。它读取页面上 Vimeo 播放器已经加载好的播放信息，把它变成视频、音频轨和封面图的下载按钮。

它不是 Vimeo 客户端、不是机器人、也不是独立下载器。它完全运行在你已经打开的 Vimeo 页面内，只能处理该页面当前正在播放的那个视频。


适合哪些场景

如果你遇到以下情况之一，这个扩展就是为你准备的：

1. 想把正在看的视频存一份到本地
   视频能在浏览器里正常播放，但页面上没有保存入口。

2. 想指定画质，而不是用默认的
   你想要 720p 或 1080p 那个文件，或者只想要音频轨，而不是播放器碰巧在串流的那一档。

3. 想要封面图
   你想把视频的封面图单独存成一个文件。

4. 想一次处理多个文件，不想重复点击
   你想在弹窗列表里勾选多项，一次性排队下载。

如果这些都不符合你的情况，浏览器自带的保存功能可能已经够用，你不需要这个扩展。


核心功能

### 页面内下载面板
打开一个 Vimeo 视频页时，扩展会在视频标题区旁边加一个小面板，固定三行：

- Video — 每个可用画质一个按钮
- Audio — 每个可用音频轨一个按钮
- Image — 封面图

某一类文件对当前视频不可用时，该行显示一个短横线占位。不刷新页面切换到另一个视频时，面板会重建。

### 视频下载
把视频保存为 MP4 文件。根据 Vimeo 播放器为该视频提供的内容，你可能会看到：

- 标注分辨率的直连 MP4 条目，例如「720p MP4」「1080p MP4」
- 标注为「1080p HD」的自适应条目，保存前会把视频轨和音频轨合并成一个 MP4
- 标注为「1080p HLS」的兜底条目，用于只提供这种交付方式的视频
- 一个「Best」按钮，自动选该视频可用的最高画质

只会列出 Vimeo 实际为该视频提供的画质。扩展不会凭空生成、放大或转码任何内容。

### 音频下载
把音频轨单独保存为 M4A 文件。按钮上标注音频码率（例如「128 kbps」），另有「Best Audio」按钮自动选最高可用码率。

### 封面图下载
把视频封面图保存为 JPEG 文件。

### 弹窗资源列表
点击扩展图标，可以看到当前标签页已解析出的全部可下载项：

- 按类型分组，显示视频、音频、图片各自的数量
- 可下载单项、勾选项或列表中的全部
- 实时进度、传输速度与单项状态
- 可清空列表并重新扫描页面

### 批量下载
下载走同一条队列，你可以一次排入多项，不必每个文件开一个新标签页。文件按顺序写入磁盘。

### 大文件
Chrome 能自行抓取的文件会交给 Chrome 自带的下载管理器，传输不依赖页面是否还开着。自适应（分片）视频只能在页面内合成，这条路径有内存预算：默认情况下，超过 768 MB 的分片视频不会被提供下载，下载过程中超出该预算也会被中止。

这个预算可以通过扩展自带的远端配置调整，无需发布新版本即可调高或调低。

### 针对 Vimeo 页面行为设计
Vimeo 是单页应用。扩展会监听视频之间的跳转，为你当前真正所在的视频重建面板，而不是展示上一个视频的过期条目。

### 不依赖播放器自己的下载按钮
扩展不会替你点击 Vimeo 播放器里的任何东西。它读取播放器已经加载到浏览器里的播放配置，并提供自己的保存按钮。


如何使用

1. 从 Chrome 应用商店安装扩展
2. 把图标固定到工具栏，方便随时打开
3. 打开 vimeo.com 或 player.vimeo.com 上的任意视频页并开始播放
4. 视频标题旁会出现下载面板，内含 Video、Audio、Image 三行
5. 点击你想要的画质，或打开扩展图标查看完整列表
6. 文件由浏览器写入你的本地磁盘

登录是可选的。登录只用于每日下载额度和订阅状态，扩展读取页面并不需要登录。


能用在哪里，以及它不做什么

适用于：
- 能在你自己的浏览器里播放的 vimeo.com、www.vimeo.com、player.vimeo.com 视频
- 指定画质或音频轨，而不是默认串流
- 保存封面图
- 在同一个页面上排队下载多项

不做：
- 下载私密、密码保护、付费或其他受访问限制的 Vimeo 视频。这些是 Vimeo 自身的访问控制，扩展无法也不会绕过它们 —— 如果播放器无法在你的浏览器里播放该视频，扩展也无法保存它
- 移除或绕过 DRM
- 读取页面尚未加载的信息
- 在 Vimeo 以外的网站上工作
- 在 Vimeo 桌面端或移动端应用上工作 —— 这只是浏览器扩展
- 任何后台爬取或抓取


常见问题

Q：使用扩展需要账号吗？
A：不需要。不登录也能下载。登录是可选的，只影响每日下载额度和订阅状态。

Q：能下载私密、密码保护或付费的 Vimeo 视频吗？
A：不能。这些限制由 Vimeo 执行，不由本扩展执行。扩展只能看到 Vimeo 已经下发到你浏览器、且你有能力播放的那个视频的播放信息。它不会解锁、猜测或绕过任何东西。

Q：能拿到哪些画质？
A：Vimeo 为该视频实际提供的那一些。典型页面会提供若干档直连 MP4，和/或一路自适应流；最高可用的一档始终会以「Best」提供。如果列表里没有更高分辨率，说明 Vimeo 没有向你的浏览器提供它。

Q：为什么有些下载有大小限制？
A：Chrome 能直接抓取的文件，扩展不会额外加限制。自适应（分片）视频必须在页面内合成，会占用内存，因此设了预算。该预算可通过扩展远端配置调整，默认 768 MB。

Q：扩展会把我的数据上传到什么地方吗？
A：媒体文件本身从不经过开发者运营的任何服务器。视频、音频和图片从 Vimeo 的服务器到你自己的浏览器，再到你的本地磁盘。扩展只在登录、每日下载额度、订阅状态和一份很小的远端设置文件上访问开发者 API。

Q：扩展需要哪些权限？
A：storage（保存你的设置与登录态）、identity（通过 Chrome 自带的授权窗口完成 Google 登录）、downloads（把文件写入你的磁盘），以及对 Vimeo 页面和 Vimeo 媒体 CDN 的访问权限，用于显示面板并获取文件。

Q：免费吗？
A：有每日免费下载额度，新账号或新设备的第一天不限次数。另有付费的 Unlimited 计划，可获得更高或不限的每日下载次数。完整列表见扩展官网的定价页。

Q：支持哪些浏览器？
A：Chrome 以及其他 Chromium 内核浏览器，例如 Edge 和 Brave。

Q：每个 Vimeo 页面都能用吗？
A：vimeo.com、www.vimeo.com 和 player.vimeo.com 上的视频页可以用。不播放单个视频的页面 —— 个人主页、信息流、搜索结果 —— 没有可供扩展读取的内容。

Q：产出什么文件格式？
A：视频为 MP4，音频为 M4A，封面图为 JPEG。


技术说明

- 浏览器：Chrome、Edge、Brave 及其他 Chromium 内核浏览器
- Manifest V3
- 网站存取权限：vimeo.com、www.vimeo.com、player.vimeo.com 以及 Vimeo 的媒体 CDN 主机
- 下载方式：直连文件走 Chrome 自带的下载管理器；分片视频在页面内合成
- 自适应视频内存预算：默认 768 MB，可远端配置
- 界面语言：14 种
