## 功能目标

让用户在 website 输入一条 Vimeo 链接，系统完成：解析资源 → 按身份授权下载 → 在执行节点上把文件交付给用户。交付统一入口：

- **客户端直连(direct)**：节点返回平台 CDN 直链，前端自行请求 CDN。
- **客户端合成(client_mux)**：节点返回独立的音视频轨道，前端合成。

交付方式只有 `direct` 与 `client_mux` 两种；早期的服务端代理交付（`proxy`，节点把文件以流的形式返回给前端）已下线，网站端不再提供。同一套链路也支撑浏览器插件在 Vimeo 页面内的本地下载（插件端不经过节点，配置改动由客户端自行决定）。

## 功能范围

### 包含

- 统一 V2 下载流程：解析入口 → 解析执行 → 下载授权 → 下载执行四个阶段。
- 下载授权 token：业务服务器通过相应身份的额度判断后签发，执行节点只验签执行。
- 下载模式统一入口：只有 `direct` / `client_mux` 两种。
- 下载 token 的语义、有效期分档、多公钥验签、签名轮换。
- V2 接口规格：解析入口、解析执行、下载授权、下载执行四个接口的请求/响应/错误码。
- 速率治理(下载链路上的并发约束与客户端速率上报)。
- 后端媒体 Provider 架构：统一 parse/download 契约、每平台一个 Provider、注册表缺失即节点不可用。
- website 前端 V2 切换：行为、超时、错误处理、灰度。
- 文件过大保护(4GiB 上限)、登录态校验、扣积分去重。
- Website 匿名下载：设备口径的永久免费次数、等待与「需要登录」三态。
- 站点适配：Vimeo 的平台识别、解析方式、`download_mode` 选择与特殊边界。
- 扩展端 Vimeo 本地下载：页面内四行下载面板（Video / Audio / Subtitle / Image）、Popup 视频面板（播放页单视频；聚合页多视频选择器，含时间裁剪）、远端可配的运行参数。
- admin 远端配置编辑入口：默认空对象，仅保存管理员实际填写的覆盖项。

### 不包含

- 积分余额查询、扣费规则、订单/订阅 → 见 `@../003.积分系统/feat.md`。
- 扩展端每日下载次数额度 → 见 `@../005.计数器系统/feat.md`。
- 下载 token 一次性消费(有效期内允许重复下载)。
- 下载中单条 TCP 连接中途自动迁移到其他节点。
- 下载字节缓存、转码缓存、对象存储落盘。
- 依赖 Cloudflare Load Balancer(节点列表由业务服务器返回)。
- 跨标签页聚合、页面刷新后的任务恢复、暂停、手动重排和下载历史；活动取消只提供给任务快照明确声明可中止的传输。
- 节点级"支持哪些平台 / 下载模式"的能力配置:所有节点统一暴露接口,缺平台配置或执行依赖时由节点返回不可用,客户端试下一个。
- 下载过程中单次请求的自动迁移:客户端只在节点超时、连不上、DNS/TCP/TLS 失败、网关不可达或返回节点不可用时换下一个。
- 私密、密码保护、付费或其他受 Vimeo 访问控制保护的视频；解析与下载都不绕过 Vimeo 的访问控制。
- 远端配置的版本分组、配置历史、回滚、发布状态、定时刷新、页面内轮询或跨页面持久缓存。

## 业务流程

### 主流程(下载)

1. 用户在 website 输入 Vimeo 链接，前端调解析入口取得有序解析节点列表(最多 3 个)。解析不强制登录。
2. 前端按顺序请求解析节点执行解析，成功后得到资源信息(平台、下载模式、资源标识、文件大小、规范链接、资源授权材料)，并记住这次解析成功用的是哪个节点。
3. 用户点击下载并通过存储检查后申请授权；匿名按设备次数直接放行、等待或要求登录，登录用户沿用账号积分规则。授权后进入既有下载流程。
4. 前端按顺序请求下载节点执行下载，按下载模式得到文件流 / 直链 / 音视频轨道。

### Website 匿名等待与批量

首页和平台页共用下载工作区。等待窗口展示标题、剩余秒数、说明、登录按钮与关闭按钮；支持键盘关闭和焦点返回，适配桌面及移动端。匿名结果卡不展示积分消耗，登录和退出后更新标签。

等待期间不请求文件；刷新和重复点击保留剩余时间。关闭窗口结束当前操作，之后不会自动下载；登录取消后继续等待，同页登录成功则继续当前下载。要求登录或跳转登录返回后，由用户再次点击下载。

批量逐项授权；当前项等待时暂停队列，关闭等待或需要登录时停止本轮，保留已完成文件，不记为失败或全部成功。策略与技术边界见 `@tech-匿名下载授权.md`，网站接入规则见 `@tech-Website匿名下载接入.md`。

### 节点切换(异常分支)

- 当前节点超时、连不上、DNS/TCP/TLS 失败、网关不可达或返回节点不可用 → 尝试下一个节点。
- 明确业务错误(token 无效/过期、资源不存在、权限不足、文件过大) → 不换节点，直接失败。

### 扣积分

登录下载授权时按用户积分口径扣减；同一用户同一资源 6 小时内只扣一次。积分余额与扣费规则见 `@../003.积分系统/feat.md`。

### 文件过大保护(异常分支)

- 业务服务器：已知文件大小超过 4GiB → 直接拒绝签发下载 token。
- 执行节点：执行前重新解析真实大小，超过 4GiB → 拒绝。
- 未知大小：只允许从头流式下载，累计发送字节达到 4GiB 上限立即中断。

### 解析节点亲和(优化分支)

前端把成功解析的节点 id 作为亲和提示传回下载授权；该节点仍在候选池时排第一，否则忽略。这只是排序提示，不是鉴权材料。

### 远端配置(分支)

1. 用户打开或刷新 Vimeo 页面，插件读取一次远端配置，同时完成页面下载能力的初始化准备。
2. 服务端返回空对象或缺少某项时，该项继续使用当前插件包内默认值；返回当前插件不认识的多余项时直接忽略，不影响初始化。
3. 读取失败时整页使用插件包内默认值继续启动，不重试、不阻断下载功能。
4. 管理员更新配置后，已经打开的页面不热更新；用户刷新页面后重新读取。

### 扩展端本地任务管理(分支)

1. 用户可从 Extension Popup 取消指定任务；页面按钮与 Popup 入口操作同一个当前 document 队列。
2. 真实下载失败保留在任务列表并继续执行后续等待项；用户可人工重试，重试项从头开始并排到 FIFO 尾部，且不重复消耗下载额度。
3. 等待中任务尚未进入额度检查，取消后立即从队列移除，不消耗额度，也不影响其它任务顺序。
4. 下载中任务由本地队列接受取消后立即移除、完成本次调用并继续下一项；底层取消和资源清理仅后台尽力执行，其结果不改变本地取消终态。
5. 取消不承诺撤销已经发出的额度请求；额度检查一旦成功，取消不退款。
6. 取消不是下载失败或额度不足，不显示失败提示；用户可以重新点击原下载入口创建新任务。
7. 同一资源在未完成列表中只保留一个任务；重复提交等待同一任务，取消作用于该共享任务。

## 非功能性需求

- 文件大小硬上限 4GiB。
- 下载 token 有效期按文件大小分档(1~6 小时)；未知大小用 6 小时。
- 下载 token 支持多公钥验签，便于密钥轮换。
- 下载 token 有效期内允许重复下载(Range 续传、刷新重试、换节点续传复用同一 token)。
- 执行节点不连业务数据库也能完成验签和下载执行(降低部署成本和泄露半径)。
- 解析和下载入口都从**同一个候选池**返回最多 3 个健康可用的节点；池内不按节点类型分层，不存在「某类节点优先、另一类兜底」的两级回退，候选池为空时返回节点不可用。
- 下载授权入口用身份短锁防双击并发；扣费去重以 Credits 下载记录的 6 小时窗口为准。
- 扩展同一 content 页面内所有入口共享一个 FIFO 下载列表，业务队列同时只有 1 个活动任务；已取消任务的底层请求可能在后台短暂收尾并与下一项重叠，不再用物理传输并发约束阻塞队列。
- 扩展端分片合成路径受内存预算约束（默认 768 MiB，可远端配置）：已知超限的候选不展示，运行中累计超限立即中断。可直连的文件不经过页面内存。
- 远端配置同时兼容多个已发布插件版本：不上传或判断插件版本，不要求服务端对象字段齐全，也不因多余字段拒绝配置。

## 验收标准

产品视角的关键验收(技术层验收见各 `tech-*.md`):

- 用户在 website 输入 Vimeo 链接 → 点下载 → 拿到文件/直链/合成产物，三种模式都从统一执行端点返回。
- 所有 Download 按钮都走统一 V2 流程，不再走旧的解析/下载/intent 接口。
- 下载授权入口收到有效亲和节点 id 且该节点仍在候选池时，优先返回该节点。
- Website 匿名下载遵守设备额度及文件大小门禁；需要登录时结束本次操作并打开登录窗口。
- 同一用户同一资源 6 小时内重复点击下载只扣一次积分；扣费后响应丢失再刷新重试不重复扣费。
- 已知文件超过 4GiB 拒绝签发；未知大小流式累计达到 4GiB 立即中断。
- 下载 token 有效期内允许重复下载；token 过期后视为新的下载动作，重新走下载授权。
- 节点缺少平台配置或执行依赖时，由节点本地接口返回节点不可用，前端试下一个节点。
- 解析/下载节点失败时前端按顺序试下一个；token 无效/过期时不换节点，引导重新授权。
- 前端不把完整 token 写入日志/埋点/控制台；平台 CDN 请求和 tracks 请求用 no-referrer 策略。
- 扣费后前端用响应返回的最新积分余额更新 UI，不再额外请求余额接口。
- 扩展同一页面的单项、批量、页面按钮和 Popup 下载按入队顺序执行，任意时刻最多 1 项下载中，其余项显示等待中；当前项失败后保留为失败并继续执行后续项。
- Popup 顶部入口按快照状态显示当前任务数量与进度；进度不可计算时显示 `…`。列表包含下载中、等待中和失败分组；失败项提供重试，waiting 始终可本地移除，活动任务只在快照声明可取消时提供取消。
- 等待中任务取消后不调用额度检查并立即消失；具备取消能力的下载中任务在本地接受取消后同样立即消失并继续队列。底层取消失败不恢复任务，取消不显示为失败。
- 同一资源重复入队时，Popup 只显示同一个任务，并等待该任务的当前执行结果。
- 下载进行时关闭再打开 Popup，仍能读取原 content 页面任务；页面刷新或关闭后不恢复旧任务。
- 远端配置为 `{}` 时，当前插件全部使用包内默认值；只覆盖一个已知项时，其余项仍使用包内默认值；包含旧客户端不认识的项时，旧客户端仍可启动并忽略该项。
- 远端配置请求失败时，页面仍按包内默认值启动；请求完成或失败前不提前绑定对应扫描与观察器。
- 管理员保存新的远端覆盖后，刷新 Vimeo 页面可读取新值；已打开页面保持本次打开时的配置，不发生中途切换。
- Vimeo 页面在标题区展示 Video / Audio / Image 三行下载面板；不提供某类资源时该行显示禁用占位，面板不消失。
- Vimeo 页面在同一 tab 内切换视频后，面板按新 videoId 重建，不展示上一个视频的过期选项。
- 聚合页（如 `vimeo.com/watch`）在 Popup 检测到多个视频时显示视频选择器，切换后信息区与四行档位联动到所选视频；播放页不出现选择器。
- Vimeo Progressive MP4 与封面图通过浏览器原生下载写入本地；分片视频在页面内合成后保存。Cloudflare 人机验证按外部环境阻塞处理，不记为产品失败。

## 用户操作逻辑与 UI 元素

> 本功能 UI 位于 website 下载入口、扩展 Popup 和 Vimeo 页面注入入口。远端配置的管理入口位于 `@../008.管理后台/feat.md`。文案需 i18n。

### website 下载入口

- **链接输入框**：用户粘贴 Vimeo 链接。占位文案提示支持的站点。
- **解析按钮**：点击后调解析入口，加载中显示 loading；失败按错误类型展示(输入错误/不支持/解析失败/解析暂不可用)。
- **解析结果区**：展示资源标题、所有者、文件名、大小(已知时)、缩略图；每个可下载资源一个 Download 按钮。
- **Download 按钮**：
  - 未登录点击 → 申请匿名授权，按结果直接下载、等待或要求登录。
  - 已登录点击 → 调下载授权，加载中显示 loading。
  - 授权失败 → 按错误展示(积分不足引导升级/文件过大/下载暂不可用/登录失效重新登录)。
  - 授权成功 → 按下载模式处理：`direct` 请求平台 CDN；`client_mux` 拉轨道并合成。
  - 授权成功后前端用响应返回的积分余额刷新 UI，不再额外请求余额接口。
- **下载状态/错误提示**：节点临时不可用自动试下一个；所有候选节点临时失败时聚合最后一个失败 code 展示下载失败；token 无效/过期引导重新点击下载。

### Extension Popup 视频面板

- **当前视频**：播放页（存在唯一主角视频的页面，如视频详情页与嵌入播放器页）面板只服务该视频，不出现视频选择器；页面切换视频或刷新后，面板按新视频重新渲染。
- **视频选择器**：聚合页（没有唯一主角视频的页面，如 `vimeo.com/watch`）检测到多个可下载视频时，在视频信息区上方显示检测数量说明与视频下拉选择器。下拉按页面检测到视频的先后列出各视频，选项文本为视频标题（缺失时回退文件名）；切换后视频信息、四行档位、音轨开关与时间裁剪整体联动到所选视频，不携带上一个视频的残留（裁剪输入清空、封面占位复位）。只检测到一个视频时选择器不出现，布局与播放页完全一致。
- **视频信息**：顶部显示封面、标题、作者、时长与当前画质；封面缺失或加载失败时在同一位置显示占位图标，不改变布局。作者与时长来自视频自身的元数据，拿不到就不显示该行。
- **四行档位**：Video / Audio / Subtitle / Image 四行，每行是「行标签 + 档位选择 + 行内下载按钮」；默认选中该行第一个档位。Image 行只有封面图与格式标识。某一行没有可用档位（如视频没有字幕）时该行选择与下载按钮不可点击。
- **音轨开关**：Video 行在画质选择之外另有一个「有音轨 / 无音轨」开关，默认有音轨；切换只改变交付内容，不改变画质。当前画质只有一种交付可选时（视频只有带音轨或不带音轨的其中一种）开关停在唯一可用的那一侧且不可点击。Audio 行不提供「不下载音频」的选项。开关状态不持久保存，重新打开 Popup 回到默认的有音轨。页面注入面板不设该开关，带音轨与无音轨仍是两个并列按钮。
- **档位大小**：档位在有可信文件大小时一并显示大小，拿不到就不显示；不展示估算值。
- **下载动作**：点击行内按钮只下载该行当前选中的那一个档位，可重复点击；不提供批量下载、勾选与清空列表。
- **时间裁剪**：可填写起止秒数只下载片段；当前画质不支持裁剪（非 DASH/HLS 交付）时输入不可用并说明原因。封面与字幕始终下载完整文件。
- **保存位置**：可填写下载目录下的子目录，默认 `vimeo-video-downloader`，随设置持久保存。只对经浏览器原生下载的档位生效（Progressive MP4、封面、字幕），文件写入「下载目录/所填子目录」；DASH/HLS 档位（含默认选中的 `Best`）在页面内合成后由浏览器保存，始终落浏览器默认下载目录，不受该设置影响。填绝对路径、`..`、盘符等非法内容时按合法部分落到下载目录内，不会写到下载目录之外。
- **空态与重扫**：当前 tab 没有可下载视频时展示空态并提供重扫；标签页不是受支持站点时展示未连接提示，不自动新建标签页。
- **尺寸**：固定 672px 宽，高度最小 300px、最大 600px；超出时只有中间内容区滚动，顶部品牌与状态栏、底部联系方式始终可见。宽度以顶部功能控件与底部联系方式整句都能完整显示为准；顶部一行放不下时功能控件折到第二行，文案不省略、不裁切。

### Extension Popup 下载状态

- **状态入口**：存在下载中、等待中或失败任务时显示在 Popup 顶部；包含下载图标、当前与失败任务数量和当前项进度。已知进度显示向下取整百分比，未知显示 `…`；全部状态为空后入口隐藏。
- **任务浮层**：点击状态入口展开浮层，标题显示任务总数，并按"下载中""等待中""失败"分组。失败行以错误色文字明确标记并提供重试按钮；waiting 和快照声明可取消的下载中任务提供取消按钮。文件名尚待队首解析时显示"获取文件名中…"。长文件名单行省略，悬停可查看完整名称。
- **大小与速度**：只在对应快照字段存在时显示。等待中任务只显示已知总大小；活动任务存在任一传输指标时显示已接收/总大小和速度。精确速度正常显示，估算速度增加 `≈`，单项缺失值显示 `--`。
- **取消按钮**：waiting 任务始终可本地移除；下载中任务只有快照声明可取消时才显示。按钮使用 `X` 图标和本地化可访问名称，不使用文字胶囊；点击后任务立即从列表消失。任务已经结束时允许返回未接受并刷新列表，不弹失败提示。
- **关闭交互**：再次点击入口、点击浮层外部或按 `Escape` 关闭；键盘关闭后焦点回到入口，入口具有可见焦点环与完整状态的可访问名称。
- **状态范围**：只展示 Popup 打开时固定目标标签页、当前 content 页面生命周期内的任务。关闭再打开 Popup 可恢复列表；页面刷新或关闭后不恢复失败项和其它任务，不提供下载历史。
- **执行顺序**：页面按钮、Popup 单项与批量入口共用同一 FIFO；失败项不占据活动位置，后续等待项继续。人工重试从头开始、恢复初始展示字段并排到队尾，不自动重试，也不重复消耗额度。

### Vimeo 页面下载入口

- **三行面板**：位于视频标题区与 Vimeo 原生 action bar 之间，固定三行 `Video` / `Audio` / `Image`。面板宽度跟随标题区域，不使用浮层，不覆盖 Vimeo 原生控件。
- **按钮**：Video 行展示 `Best` 与所有可用画质；Audio 行展示 `Best Audio` 与所有独立音频轨；Image 行展示封面图。`Best` / `Best Audio` 使用主按钮样式，其余使用次按钮样式。
- **无资源占位**：某一行没有可用资源时显示禁用的 `-` 占位按钮，行标签仍在，面板不消失。
- **下载中状态**：点击任一资源后锁定该视频面板的全部可下载按钮，阻止重复下载与重复扣额；触发按钮显示整数百分比，缺少可信总字节时显示本地化的下载中文案。完成或失败后恢复原画质文案与可点击态。
- **按钮尺寸稳定性**：按钮用不可见的本地化忙碌文案预留宽度，下载状态与百分比变化不改变按钮尺寸。
- **SPA 切换**：Vimeo 站内路由切换后按新 videoId 重建面板与资源缓存，旧面板立即移除。
- **登录与额度**：未登录也能使用面板；额度不足时展示升级或登录引导，不改变面板布局。
