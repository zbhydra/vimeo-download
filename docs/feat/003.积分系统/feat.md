## 功能目标

Credits 是账号维度的下载额度。本域保留 Credits 的后端能力：账户余额与流水、注册赠送与购买到账、账号下载授权的体积阶梯扣费、积分包商品定义。**网站不再提供 Credits 的展示、消费和购买入口**：网页下载免费、匿名，没有账户和 Credits（见 `@../002.下载功能/feat.md`）；Pricing 页只销售插件订阅（见 `@../011.Pricing页/feat.md`）。网站同时不再提供签到入口。后端保留 Credits 余额与流水、注册赠送、账号下载授权扣费、积分包商品定义与购买到账链路（网站均不再调用），等待独立的「积分 / 签到下线」任务统一处理（决策出处：004 官网改版计划 §8）。

## 功能范围

### 包含

- Credits 余额：用户账户余额、流水、查询口径。
- Credits 获得：注册赠送、存量补发、购买积分包到账；注册赠送是否可发由用户系统的 IP 注册权益风控决定。
- Credits 消耗：账号下载授权按文件体积阶梯扣费，后端保留，网站不再调用。
- Credits 6 小时免重复扣费：同一用户同一下载产物 6 小时内重复授权不重复扣积分。
- 积分包商品定义：商品档位、Credits 数量、美元展示价、Clink / PayPal 渠道价、排序（订单履约流程本身在 `@../004.订单系统/feat.md`）。

### 不包含

- 网站上的 Credits 余额展示、积分不足购买弹窗、Pricing 积分模式与积分包购买入口：均已下线，网站不再调用对应后端接口。
- 下载解析、下载授权 token、下载执行链路、三种下载模式 → 见 `@../002.下载功能/feat.md`。
- 订单创建、支付渠道对接、支付 webhook、订单履约给用户加积分的事务 → 见 `@../004.订单系统/feat.md`（本域只提供积分包商品定义和到账写流水的 service 能力）。
- 扩展端每日下载次数额度、设备匿名下载规则 → 见 `@../005.计数器系统/feat.md`。
- 退款、撤销、人工补单、转赠、代充。
- IP 注册权益风控的判定、注册 IP 辅助表、签到拦截归用户系统；本域只提供加 Credits 能力。

## 现状说明

网站下载不再以 Credits 为准：网页下载全部匿名、免费，已有账号的 Credits 余额在网站上不再有消费和展示入口，后端余额数据保留。账号下载授权的扣费规则仍在后端生效（供未来入口使用），旧的网页每日 quota 已停止扣费。

**扩展端不在本域**：扩展下载使用每日次数口径，由计数器系统提供（`@../005.计数器系统/feat.md`）；扩展端不消耗 Credits、不写 Credits 流水、不写下载记录。

## 业务流程

### 账号下载扣 Credits（后端保留，网站不再调用）

1. 调用方走账号下载授权；授权链路、resource token 透传、节点候选见 `@../002.下载功能/feat.md`。
2. 业务服务器在下载授权阶段验签 resource token，拿到可信的资源信息。
3. 按「同一用户同一资源 6 小时窗口」判断是否免扣；命中时不扣积分继续下载，未命中时按体积阶梯扣减。
4. 扣减口径固定为登录用户（不按设备、不按会话）。
5. 余额不足时不写扣费流水、不写下载记录，授权失败。
6. 扣费细节（阶梯算法、免扣窗口、token 内容）见 `@tech-数据模型与扣费.md`。

### 积分包购买（后端保留，网站不再提供入口）

积分包商品配置、订单创建、支付、履约到账的后端链路保留，合同见 `@tech-购买.md` 与 `@../004.订单系统/feat.md`。网站没有入口触发该链路。

## 非功能性需求

- 不新增第三方依赖；不新增依赖注入。
- Credits 永不过期。
- 积分到账只发给对应账号。
- 支付成功后不支持退款。
- 错误信息必须能定位到用户、订单、商品、支付方式。
- 不做金融级对账和退款系统；失败让用户重试，履约失败走订单补偿。
- 商品美元展示价、渠道价必须都走配置表，不允许写死在前端。

## 验收标准

产品视角的关键验收（技术层验收见各 `tech-*.md`）：

- 网站任何页面都没有 Credits 余额、积分购买、签到入口；网页下载不扣 Credits。
- 账号授权下，同一用户同一资源 6 小时内重复授权只扣一次积分；并发请求同一资源时只有拿到锁的请求扣费，其他返回重试。
- 积分包商品配置与订单履约后端链路保持可用，余额数据保留。
- 扩展端下载不扣 Credits、不写积分流水、不写下载记录（口径见 `@../005.计数器系统/feat.md`）。

## 用户操作逻辑与 UI 元素

本域在网站和扩展上没有用户界面：下载工作区与 Pricing 页均不展示 Credits，购买弹窗已删除。

## 数据埋点

网站不再产生 Credits 消费与积分包购买相关的打点。历史事件名与后端 mark 字典中的取值保留，不再有网站来源的新数据。
