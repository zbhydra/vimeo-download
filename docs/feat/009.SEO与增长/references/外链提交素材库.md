## 提交素材使用规则

1. **tagline ≤60 字符、描述 ≤140 字符**是多个平台的硬限制（AlternativeTo、Crunchbase、IH 实测），先取对应长度版本再填，不要提交后被截断。
2. **链接指向**：website 场景贴站点 URL；extension 场景贴商店 URL；两者都收的平台优先贴站点（自然导流到插件）。
3. **图片**：og-image.png 同时当 icon 和 screenshot 用过（AIToolboard/AlternativeTo/IH）。要求"方图 icon"的平台需另出一张 512×512 方形 logo（当前缺，见待办）。
4. **每提交一个平台，在 `@../plans/002.外链平台批量提交.md` 记一行**，状态与日期必须同步。
