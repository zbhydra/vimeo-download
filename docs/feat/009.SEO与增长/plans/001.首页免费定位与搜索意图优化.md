> 状态：本轮已授权实施，产品决定已定稿，尚未部署。内容决定以 [page_seo.md §3.1](../../../seo-skill/homepage/page_seo.md#31-首屏决定与元数据) 为准，确认文案以 [en-US.md](../../../seo-skill/homepage/en-US.md) 为准。本文件只跟踪实施与验收，部署、Title 实验与文章发布未获授权。

## 1. 交付目标与依赖

让用户理解并完成免费网页 MP4 下载，再按音频、字幕或队列需求进入插件；沿用增长域现有的插件安装与订阅业务目标，保留已有关键词、插件能力与使用教程的承接。插件卡保持当前默认展开；H1 使用突出免费且移除 Any 的确认稿，Chrome/Edge 卡片保留现有 14 语言原文，唯一例外是德语 Description 人称统一为 Sie，保留 jedes / fast 承诺，德语 Title / CTA 及其他 13 语言卡片不变。

产品决定已解除实施依赖；共享组件与 14 语言同步后一起验收，避免网页步骤与插件步骤混用。下载状态机保持原行为，不增加收起方案用例，也不触发下载域合同同步；获得发布授权后才记录上线与效果。

事实与状态 owner：U1（hp-web-worker）负责全部 `website/src`、首页测试及运行时变更摘要；U2 负责 llms Home 描述、增长域合同和本计划、首页 SEO 工作区的状态同步。架构师汇总产品决定及 U1 / 集成验收的实际结果；本计划 §5 是本次实施与验证记录的唯一明细，未收到摘要的项目不标成功。

## 4. 最少验证

U1 / 集成 worker 统一负责构建、定向用例及真实后端流程；U2 只做文档格式、相对链接 / 锚点与索引路径、内容一致性校验，不重复构建、启动或运行应用测试。

### 4.1 构建与定向用例

在 `website/` 中依次执行：

```sh
pnpm build
node --test --test-name-pattern='^every locale homepage has one H1' tests/module-scripts.test.js
```

复用并修改既有首页用例，不运行整套 module-scripts 或完整 e2e。断言覆盖：单一 H1、8 个区块的新顺序、网页三步、插件四步、原有结构化数据、有效同语言指南链接；没有正文的 locale 不输出链接。增加对 `#home-intro` 内全部 H2 元素恰好一个的断言，不依赖标题 class，避免插件步骤误用 H2 而漏检。指南可用性按构建产物中的实际文章判断，不复制语言白名单。继续保留展示文案的数字限制。

插件卡显隐未改，不增加收起方案或下载状态机的定向用例。

### 4.2 最少真实页面检查

- 启动前先用 `lsof -nP -iTCP:7900 -sTCP:LISTEN` 找到监听 PID，再用 `lsof -a -p 实际PID -d cwd` 核对是否属于本仓库 `backend/`；若被其他项目占用，先解决本仓库的端口与 API 配置，不误用其服务或停止其他项目进程。之后启动或复用本仓库的真实后端与 website，API 指向本地；不使用 mock、伪造响应或生产 API 回退。
- 英文首页检查桌面 1440px、手机 390px；再以较长本地化文案的一个 locale 在手机检查换行。确认教程前移和插件四步迁移后的 hero 高度、插件入口、三列/时间线、无横向溢出和可见键盘焦点。
- 首访卡片保持默认展开，一行入口随卡片可见而隐藏；真实解析与下载流程中检查既有显隐未回归。核对 H1 使用确认的免费稿、两张卡片按 §1 保留原文及德语 Description 人称例外，不将卡片的 any / fast 视为本次待修复项。不为验证状态伪造后端响应。
- 检查指南可达并能回到首页，安装和方案链接指向正确目标；仅核对导航，不安装插件、不下单。
- 用一个小型、可访问且有权下载的公开视频，完成一次真实解析与 MP4 下载，确认新三步文案和实际交互一致。无需逐语言重复下载。
- 核对已有点击与下载事件的发出情况；GA4 接收或历史数据不可用时如实记录，不新增统计系统作为兜底。
