## 1. 已确认决策（hydra，2026-10-05）

1. Pricing 订阅页的地址改回 `/ext-pricing/`，14 语言同步。`/pricing/` 直接删除，不做跳转，与 004 处理其他删除路由的方式一致。

6. 舞台上的格式标签（`1080p`、`HLS → MP4`、`M4A`、`VTT`）不走 i18n。

### 2.2 视觉系统

**中性色：Geist token 名不变，值换成深色。**

这和 Geist 自己的暗色主题（`docs/references/specs/design.dark.md`）是同一种做法：语义名不变，值翻转。组件里约 300 处 token 引用会自动跟着变深，见 §3。

D 用的是偏蓝的深色，不是 Geist 的纯中性黑灰。新增的 `--gray-200` 也是 Geist 原有名字。

| token | 现值 | D 值 | 语义 |
| --- | --- | --- | --- |
| `--background-100` | `#ffffff` | `#070B18` | 页面底（`body`） |
| `--background-200` | `#fafafa` | `#0A1020` | 次级底：交替区块 |
| `--gray-100` | `#f2f2f2` | `#0E1529` | 组件底：卡片、弹窗、输入框 |
| `--gray-200`（新增） | — | `#131C36` | 组件悬停、卡内填充 |
| `--gray-alpha-100` / `-400` / `-500` / `-600` | 黑色 alpha | `rgba(148,163,255,` 0.06 / 0.12 / 0.22 / 0.28 `)` | 分隔线、描边 |
| `--gray-700` | `#8f8f8f` | `#7E88A4` | 占位、禁用、次要文字 |
| `--gray-900` | `#4d4d4d` | `#A3ACC4` | 次文字、正文 |
| `--gray-1000` | `#171717` | `#E3E8F5` | 主文字、标题 |
| `--blue-700` / `--blue-800` | `#006bff` / `#0059ec` | `#8AB4FF` / `#A9C6FF` | 品牌文字、链接 |

状态色按同一规则翻转：

- `-100` / `-200` 是同色相 alpha 0.10 / 0.16 的底；
- `-400` / `-500` 是 alpha 0.28 / 0.45 的描边；
- `-900` 是同色相的浅色文字：红 `#FCA5A5`、琥珀 `#FED7AA`、绿 `#86EFAC`。

阴影 token 改成深色写法：

- `--shadow-card` 为 `inset 0 1px 0 rgba(255,255,255,.04), 0 20px 40px -24px rgba(0,0,0,.6)`；
- popover 与 modal 改为 `0 24px 48px -12px rgba(0,0,0,.6)`。

**品牌与装饰 token**（Layout 全局块）。跨组件使用的颜色只能从这里或上表取。

| token | 值 | 用途 |
| --- | --- | --- |
| `--brand-500` | `#2D6AE8` | logo 实测主色：图标底块、非文字的实心强调 |
| `--brand-600` | `#1F4FCC` | 主按钮渐变终点 |
| `--gradient-button` | `180deg, #2F6BEA → #1F4FCC` | 主按钮 |
| `--gradient-brand` | `100deg, #2F6BEA → #5B5BF0 → #6D4AE6` | 带字的渐变：步骤数字、Most Popular 徽标 |
| `--gradient-brand-text` | `100deg, #8AB4FF → #A78BFA → #C4B5FD` | H1 品牌词（渐变文字） |
| `--gradient-border` | `140deg, rgba(138,180,255,.75) → rgba(167,139,250,.35) → rgba(103,232,249,.55)` | 1 px 渐变描边：舞台输入框、插件窗口、主推价格卡、收尾 CTA 卡 |
| `--neon-cyan` | `#67E8F9` | 勾选图标、标注圆点 |
| `--glass-bg` / `--glass-border` | `rgba(255,255,255,.06)` / `rgba(255,255,255,.12)` | 玻璃面：次按钮、一行入口、登录条、日期胶囊 |
| `--shadow-glow` | `0 8px 20px -8px rgba(45,106,232,.65)` | 主按钮光晕 |
| `--radius-lg` / `--radius-xl` / `--radius-2xl` | 16 / 20 / 24 px | 输入框卡片、普通卡片、主卡 |

**规则**：

- `:root` 设 `color-scheme: dark`，让原生控件和滚动条也是深色。
- 正文基准字号从 14 px（`Layout.astro:273`）改为 16 px；系统字体不变（沿用 004 决策 6）。
- 纯白（`#fff` / `#ffffff` / `white`）只用于两处：主按钮上的文字、Chrome 图标的小白底板。其余一律用上表的色值。
- 按钮：
  - `.btn-primary` 用 `--gradient-button` 底、白字、`--shadow-glow`；
  - `.btn-secondary` 改为玻璃样式：`--glass-bg` 底、`rgba(255,255,255,.16)` 描边、`--gray-1000` 字。全站只有这一种次按钮。
- 深色舞台只有一个实现：V1 新建的 `components/site/SiteStage.astro`（见 §2.3 外壳）。舞台的底色渐变（`#070B18 → #0B1226`）、极光、网格、星点、光束、格式标签只写在这个组件里。
- 插件界面示意（页内面板、popup）抽成一个组件，首页插件展示和收尾 CTA 共用。示意里调暗的浅色只写在这个组件里，不进全局：网页底 `#E6EBF3`、popup 底 `#EDF1F7`，以及取自插件 `buttons.css:68-76` 的 Vimeo 青 `#00ADEF`。
- 只在单个组件里用的其他装饰色，也留在该组件 scoped 的 CSS 变量里。例如功能卡的 5 组图标色：同色相 alpha 0.14 的底，配浅色线条。
- 对比度（WCAG 公式计算）：

  | 前景 | 在页面底 | 在组件底 |
  | --- | --- | --- |
  | `--gray-1000` | 16.0:1 | 14.8:1 |
  | `--gray-900` | 8.7:1 | 8.0:1 |
  | `--gray-700` | 5.6:1 | 5.1:1 |
  | `--blue-700` | 9.4:1 | 8.7:1 |

  - 状态色文字在自己的 `-100` 底上都 ≥ 7.7:1；
  - 主按钮白字 ≥ 4.76:1；
  - `--gradient-brand` 上的白字 ≥ 4.76:1，渐变终点不浅于 `#6D4AE6`（5.6:1）；
  - `--brand-500` 只用于非文字图形（4.05:1 ≥ 3:1）。
- 焦点环：
  - 沿用 spec-website §4 的 0,4,0 规则。新组件在可交互元素上写 box-shadow 时，按该条款排除 `:focus-visible`；
  - `--focus-ring` 改为 `0 0 0 2px #070B18, 0 0 0 4px #8AB4FF`，环色对页面底 9.4:1。
- 动效：
  - 只允许舞台里的循环装饰动效：光束、扫描线、透视地面；
  - 只动画 transform 与 opacity。效果稿里扫描线动的是 `top`、地面动的是 `background-position`，实现时都改成 transform 位移；
  - `prefers-reduced-motion: reduce` 时全部停止；
  - 不做入场动效、滚动触发动效，也不用 JS 驱动动画。
- 不做：明暗主题切换（全站只有深色一套）、字体依赖、`/pricing/` 跳转。
