> 已实施（2026-10-05，基线 `a30dc4b`；验收记录见 §10）。范围：`website`（并入 `website-shared`）、插件 1 个路径常量及其单测、后端匿名下载策略的种子数据（不改后端代码）。§1–§9 为实施前批准的基线。

## 1. 已确认决策（hydra，2026-10-05）

1. 网站定位：插件展示站 + 插件订阅购买。下线 Credits 积分包页与余额展示、签到入口；删除 `/vimeo-downloader/` 与 `/changelog/`。
2. 网页下载保留并免费：次数与大小上限「先改到无限大」，机制本身保留。
3. 网页下载器放在首页首屏，下方接插件展示区块。
4. 后端与后台的签到、积分系统本次不动。
5. 结构遗留一并收敛：`website-shared` 并回 `website/src`，移除未使用的 Vue 集成与 React JSX 配置。
6. 全站使用 `design.md` 的 Geist 亮色、系统字体，不新增字体依赖。

### 2.2 首页

- 首屏是网页下载器，页面唯一 H1 仍为工具标题，下方保留 trust points。
- 首屏之后依次是以下区块，各一个 H2，纯静态、无客户端脚本：
  1. **插件介绍**：一句话定位；主按钮「Add to Chrome」跳商店，次按钮进 `/pricing/`；配一个用 HTML/CSS 还原的插件页内面板示意（Video / Audio / Subtitle / Image 四行），不用第三方视频截图。
  2. **功能**：卡片网格，内容取自商店文案「CORE FEATURES」：页内面板、画质选择与 Best、音频 M4A/MP3、字幕 VTT 与剪辑、封面 JPEG、Popup 资源列表与队列、大文件、设置与历史。
  3. **使用步骤**：安装 → 固定图标 → 打开 Vimeo 视频页 → 选择画质。
  4. **网页版与插件对比**：维度为运行位置、可保存的资源类型、批量 / 队列、大文件、是否需要登录、费用。每格都要对照源码与商店文案核实后填写。
  5. **适用范围与边界**：商店文案「WHAT IT WORKS FOR / DOES NOT DO」与「LEGAL AND COMPLIANCE」的精简版：不绕过访问控制、不去除 DRM、只支持 Vimeo、与 Vimeo, Inc. 无关联。
  6. **方案概览**：Free（每日免费额度、新账号或新设备首日不限）与 Unlimited 两张卡，按钮进 `/pricing/`。不写具体次数与价格，两者都来自后端配置。
  7. **FAQ**：网页工具与插件的问题合并，输出 FAQPage JSON-LD。
  8. **结尾 CTA**：Add to Chrome。

### 2.3 网页下载免费化

- 下载授权固定走匿名接口，与是否在 Pricing 页登录过无关。删除登录态授权分支和前端的 `download-pre-v2` 调用。
- 工作区移除以下内容，以及只服务这些功能的打点：
  - 登录弹窗、账户入口与退出；
  - Credits 标签与余额、积分购买弹窗；
  - 签到弹窗与自动弹出；
  - 工作区内的订单结算弹窗。
- 状态 2（等待）：保留倒计时与关闭，删除「登录免等待」按钮。等待窗目前借用登录弹窗的全局样式（`DownloadAnonymousModal.astro:6-12` 的 `.download-auth-*` 类定义在 `DownloadAuthModal.astro:115` 的 `is:global` 块），登录弹窗迁出后它必须自带样式。
- 状态 3（需要登录）：
  - 不再打开登录。本次点击视为用户中止，不记为失败。
  - 工作区提示「该资源需用插件下载」，并展示已有的插件引导卡（`data-download-large-file-extension-inline`）。
  - 批量下载沿用现有语义停止本轮，已完成的文件保留。
- 下载归属统一为设备（`device:{device_id}`）。登录态遗留的续传记录不做兼容，用户重新下载即可。
- 策略放开只改数据，不改代码：

  | config_public 键 | 现种子值 | 新值 | 说明 |
  | --- | --- | --- | --- |
  | `dl_anonymous_immediate_count` | 2 | 2147483647 | 与 total 相等，不出现等待区间 |
  | `dl_anonymous_total_count` | 3 | 2147483647 | 实际不会触发次数墙 |
  | `dl_anonymous_wait_seconds` | 300 | 0 | |
  | `dl_anonymous_max_size_bytes` | 314572800 | 4294967295（4 GiB − 1） | 与系统上限等价，只有恰为 4 GiB − 1 或 4 GiB 的文件走状态 3 |

  - 大小不取更大的值：resource token 签发时会直接拒绝大于 4 GiB 的 size（`media_resource_token_service.py:394`），后端 real 用例按策略值 ±1 签发 token，取 4 GiB − 1 时用例无需改动。
  - `dl_anonymous_dedup_seconds`、`dl_active_download_limit`（每设备并发 3）不变。
  - `config_init.sql` 的种子只影响全新环境。已有环境（本地 / 测试 / 生产）按发布单执行同值 UPDATE，再调用后台刷新配置缓存（`POST /api/admin/system-settings/config-cache/refresh`）。
- 后端代码不改：大小未知的资源仍返回状态 3，由上面的状态 3 处理承接。

### 2.5 支付回跳页

- PayPal 与 Clink 共用一个回跳组件、一份英文文案和一个脚本模块。
  - 脚本迁出 `credit-purchase/`，保留 `order/cancel` 调用。
  - 删除页面内硬编码的文案和脚本内置的文案。
- 文案去掉 Credits，改为订阅或通用表述；「返回价格页」固定为 `/pricing/`。
- success 页在「本页无法确认订单」时展示中性的「已提交」：回到发起购买的地方查看；在插件内购买的，重新打开插件即可看到套餐。不再显示「Payment needs attention」。「无法确认」包括三种情况：
  - 没有网站登录态（插件内购买的常态）；
  - 网站 token 失效（401）；
  - 订单不属于当前网站账号（后端返回订单不存在，`order_client.py:161`）。
- 能查到订单时保持现有轮询：已支付显示确认，后端明确的取消 / 过期 / 失败显示失败。

4. **首页。**

   - 站点默认 meta description 改为新定位；
   - 插件面板的行标签随语言本地化；
   - Free 卡按钮改为泛指的「查看方案」。
5. **3a。** 移动端保留语言切换，Install 加入菜单。
