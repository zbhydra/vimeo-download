# Pricing 购买页拆分

> **部分作废**：本计划成文于多平台时期。Instagram / X / Telegram / Threads 站点与 `website-tgd-pro`、`extension-pro` 已随单平台（Vimeo）转型整体删除，文中这些平台与站点的条目只作历史记录；现行架构以 [`../../002.下载功能/tech-站点适配.md`](../../002.下载功能/tech-站点适配.md) 与 [`../../002.下载功能/references/index.md`](../../002.下载功能/references/index.md) 为准。（**2026-09-20 补注**：原指向的 `../tech-站点适配.md` / `../references/index.md` 在本域内不存在，这两个文件都属 002 下载域，已补全相对路径。）
已获用户批准的实施计划。范围：`website` 与 `website-tgd-pro` 两站均修改。

## 目标与验收合同

- 两站 `/pricing/` 只展示、加载和购买积分商品；`/ext-pricing/` 只展示、加载和购买插件订阅商品。无来源参数也能直接访问订阅页并购买。
- 英文根路由与全部现有语言路由同步支持；页面标题、说明、FAQ 和 SEO 文案与当前商品一致，静态 HTML 即为对应页面内容。
- 插件继续打开原 `/pricing/` URL，网站前端识别后跳转到同站、同语言的 `/ext-pricing/`，完整保留查询参数和 hash。使用替换当前历史记录的导航，避免后退再次进入中转页。
- 跳转页不启动商品加载、购买恢复和 Pricing 业务曝光；这些行为在目标页执行一次。目标页刷新仍按原规则记录曝光。
- 页面商品类型由路由装配时确定；插件来源标记只用于旧入口转向、登录同步与来源埋点，不再决定商品类型。
- 语言切换保持当前购买页类型；插件来源参数按各站现有规则保留。OAuth 回跳保持当前页与一次性购买意图。
- 复用各站自己的登录、支付弹窗、订单创建、支付状态查询和账号刷新链路。主站的安装确认、好评赠送资格与来源限制、订阅管理规则不变；Pro 不增加好评赠送。

## 实施前证据与修改范围

### 主站

- [插件导航](../../../../extension/src/core/utils/navigation.ts)：`buildPricingUrl` 构造原 Pricing URL，多个额度与升级入口调用 `openPricingPage`。插件无需发版或改代码。
- [页面装配](../../../../website/src/components/pages/PricingPage.astro)、[共享页面壳](../../../../website-shared/src/components/pricing/PricingPageShell.astro)：当前默认同时装配积分与订阅。新增根目录及 `[lang]` 下的 `ext-pricing.astro`，两个购买页复用现有页面装配，传入明确的商品模式；替换 `showSubscription` 这类不再完整表达页面类型的开关。
- [页面控制器](../../../../website-shared/src/components/pricing/pricing-page-controller.ts)：`readPricingEntryFlags` 当前以 `utm_source=extension` 或 `source=quota_counter` 识别插件来源；保留此规则用于跳转。`initPricingPage`、商品加载、DOM 获取和购买恢复按页面类型收敛，订阅专属操作不在积分页初始化。删除来源切换布局及不可达的积分来源分支，保留真实来源埋点。
- 主站账号摘要和现有订阅管理入口保留；“只保留积分购买”限制购买商品，不删除账户已有权益信息。好评活动仍只在原有条件满足时出现。
- [i18n](../../../../website/src/i18n/pricing.ts) 与 schema 按积分、订阅整理所需标题、描述及 FAQ；同步页面结构化数据。[站点布局](../../../../website/src/layouts/Layout.astro) 与 [sitemap](../../../../website/src/sitemap/languageSitemap.mjs) 检查新路由的语言链接、canonical 和路由元数据。

### Pro 站

- 插件导航（`../../../../extension-pro/src/core/utils/navigation.ts`，已随目录删除/失效） 继续构造原 URL；不改插件。
- 页面装配（`../../../../website-tgd-pro/src/components/pages/PricingPage.astro`，已随目录删除/失效） 新增明确商品模式，根目录及 `[lang]` 下新增 `ext-pricing.astro`。SSG 按模式输出对应内容，删除浏览器按来源替换标题、文案及 FAQ 的逻辑。
- 来源识别（`../../../../website-tgd-pro/src/scripts/site/extension-auth.ts`，已随目录删除/失效） 的 `isExtensionPricingEntry` 保留严格条件：恰好一个 `utm_source=extension`，恰好一个 `source` 且为 `quota_counter` 或 `quota_upgrade_button`。复用它识别旧入口跳转和初始 token 补发，不扩大回传条件。
- 支付控制器（`../../../../website-tgd-pro/src/scripts/payment/payment-controller.ts`，已随目录删除/失效） 的 `consumePurchaseIntent` 当前要求插件来源；改为要求订阅页及既有合法购买意图，覆盖无来源参数直接购买后的 Google 回跳，不新增持久状态。
- 语言切换器（`../../../../website-tgd-pro/src/components/site/LanguageSwitcher.astro`，已随目录删除/失效） 将来源参数保留逻辑应用于新订阅路由；SEO 产物（`../../../../website-tgd-pro/src/seo/site-assets.mjs`，已随目录删除/失效） 及 i18n 同步新页面信息。

## 范围边界与取舍

- 两个站点独立实施，不创建跨站路由、组件或支付抽象，不新增依赖、接口、表、状态机或版本识别。
- 站点通用 Pricing 导航仍进入积分页；订阅页可直接访问，也由插件旧链接进入。此次不增加导航项或交叉销售入口。
- 主站现有 PayPal、Clink 独立支付返回页的通用“返回价格页”链接仍指向 `/pricing/`；原购买页继续负责订阅支付后的账号刷新。此次不新增订单类型追踪或支付返回路由协议。
- 前端重定向需要 JavaScript；禁用 JavaScript 时原 `/pricing/` 保持积分静态内容。这与动态购买所需的浏览器运行环境一致。
- 没有后端支付协议或商品规则变更;运行验收见下方记录。

- 以上检查合并覆盖：直接访问两页只请求对应商品；旧插件入口转向且 URL 信息保留、业务曝光不重复；英文和一个非英文语言切换正确；无来源订阅购买在登录回跳后继续；积分下单类型为积分、订阅下单类型为订阅；订阅支付完成后刷新权益；主站原好评与有效订阅限制仍生效。
