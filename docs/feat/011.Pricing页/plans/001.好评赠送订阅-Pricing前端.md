# 001 · 好评赠送订阅 - Pricing 前端

## 目标

在 Pricing 订阅购买确认中交付好评赠送入口、Chrome Web Store 跳转、30 秒检测、领取结果与错误重试。

## 依赖 plan

依赖 `@../../006.订阅系统/plans/003.好评赠送订阅-后端.md` 的配置字段和领取 API。

## 改动范围

1. 新增 Pricing 专用订阅确认弹窗,替换订阅入口对全站通用确认框的调用。
2. 接入领取次数,登录成功后重新加载订阅配置。
3. 完成商店 `/reviews` 跳转、30 秒内存倒计时和领取 API。
4. 完成成功、已领取、失败、服务器繁忙与直接重试视图。
5. 补齐全部 Pricing locale、无障碍与桌面/移动验收。

## 文件或模块责任

- `PricingSubscriptionConfirmModal.astro`:弹窗 DOM 与样式。
- `pricing-subscription-confirm-controller.ts`:当前弹窗生命周期与状态转换。
- `pricing-checkout.ts`:领取 API client 和响应类型。
- `pricing-page-controller.ts`:配置次数、登录后刷新、账号刷新与 checkout 分流。
- `PricingPageShell.astro`:装配专用弹窗。
- `website/src/i18n/schema.ts`、`pricing.ts`:全部语言合同。
- `website/e2e/`:新增连接真实后端的独立 smoke 入口,不进入默认 mock project。

## 执行顺序

1. i18n schema 与 API 类型。
2. 专用弹窗静态结构和初始确认视图。
3. 页面状态接入、商店跳转、倒计时、领取与重试。
4. 无障碍、响应式与生命周期清理。
5. 真实联调、类型、构建、启动和浏览器视觉检查。
6. 实现完成后更新 011 changelog 的实现与验证记录。

## 验收标准

- 领取次数 0 才显示指定赠送文案与按钮。
- 点击去好评后同一弹窗进入检测,不再出现继续购买。
- 新标签页 URL 精确落到插件 `/reviews`。
- 30 秒前不领取,到时只请求一次;失败重试不重新计时。
- 成功/已领取刷新账号并结束购买;关闭/刷新不恢复。
- 全站通用确认框和 Credits checkout 行为不变。
- 全语言、键盘、读屏、移动端和桌面布局通过。

## 验证命令

```bash
cd website
pnpm test:module-scripts
pnpm tsc --noEmit
pnpm build
```

再启动 website,连接已完成后端,用桌面和移动视口完成真实账号 smoke。测试不得 mock 项目 API、MySQL、Redis、鉴权或业务 service。

## 风险与恢复

- 浏览器后台标签页可能延迟 timer,允许实际领取晚于 30 秒。
- 商店页打开失败不阻断检测界面关闭,不增加跨标签通信。
- 回滚方式为移除专用弹窗入口并恢复原订阅确认调用;后端已领取事实和订阅时长不回退。
