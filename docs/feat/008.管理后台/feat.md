# 008 · 管理后台

> 产品需求文档。只描述"后台有哪些管理模块 + 边界 + 用户操作 / UI"。技术实现(SPA 架构、各模块接口规格、节点本地 vs 中心 admin 入口、admin JWT-only 认证)见同目录 `tech-*.md`。
> 本域是面向运营管理员的独立后台，只承载管理能力。订单数据本身见 `@../004.订单系统/feat.md`，下载记录与下载统计口径见 `@../002.下载功能/feat.md`，积分见 `@../003.积分系统/feat.md`，客户端用户见 `@../007.用户系统/feat.md`。

## 功能目标

为运营管理员提供一个**独立部署、与 public website 物理隔离**的管理后台,集中承载日常运维与排障所需的只读查看与受控写入能力,替代此前散落在 CLI 脚本和文件系统的人工操作。

管理后台是一个独立的单页应用,不是 website 的一部分。它部署在独立域名,有自己的登录入口、自己的管理员账号体系、自己的会话与令牌。管理员通过浏览器进入后台,完成账号登录后,在侧边栏切换各管理模块。

## 功能范围

### 包含

- 管理员登录、登出、Access Token 自动续签、中英文切换。
- 运营 Dashboard:用户与打点统计(60 天按天聚合),只读。
- 订单管理:只读查询订单列表与详情,支持多维度筛选,不做任何写操作。
- 系统设置:提供低频运维动作,支持手动刷新全部配置读取缓存、生成 / 轮换当前管理员的外部 API Key、编辑扩展读取的远端配置稀疏覆盖对象。
- 外部 API:第三方系统可用管理员生成的 API Key 访问独立的外部 API 分组,当前只提供系统统计大盘。
- 通用用户信息弹窗:后台内所有可点击的用户 ID 都可打开同一个用户详情弹窗,展示用户基础信息、Credits、订阅状态、最近下载记录、积分记录和订单列表。
- 管理后台所有时间展示统一为 `YYYY-MM-DD HH:mm:ss`,固定按 UTC+8 显示。
- 下载详情列表:只读查看下载开始 / 成功 / 失败三类记录,辅助排障。
- 解析失败排查:只读查看解析失败打点,并对单条失败链接触发一次重新解析。
- 服务节点管理:节点的增删改、启用 / 停用、手动健康检查(详见 `@feat.md`)。
- 节点本机监控:查看各节点本机网络进出速率。
- 数据分析:下载资源分布(按大小分桶,展示次数占比)、下载用户排名、下载统计汇总、用户注册地区分布(展示人数占比)、每日充值(+8)、商品统计(+8),六个只读子标签页,统一时间范围筛选。
- 代理池管理:维护动态/静态代理配置的列表、批量新增、编辑、启停和物理删除；当前只保存管理数据，不检测可用性，不接入消费链路(详见 `@tech-代理池.md`)。
- 管理员账号通过 CLI 创建,不在后台 UI 增删改。

- 客户端用户认证、用户注册登录(属 `@../007.用户系统`)。
- 节点本机 admin 本地认证(属 `@feat.md` 的节点本地管理边界)。
- 管理员角色的细粒度权限控制(RBAC):当前所有管理员权限相同。
- 管理员的增删改查 UI:通过 CLI 管理。
- 多 API Key 管理、API Key 权限分组、API Key 调用审计、API Key 过期策略。

- 监控的历史曲线、趋势图、告警、峰值统计。

### 域边界事实(四套认证边界)

系统同时存在四套互不混用的认证边界,管理后台负责其中两套:

1. **管理后台 admin 认证(本域)**:独立的管理员账号表 + 账号密码 + 图片验证码登录,签发独立的 admin JWT(Access + Refresh)。Access Token 默认有效期 30 分钟,Refresh Token 默认 7 天。业务服务器负责登录、签发与续签;节点本地管理接口只验签 Access Token,不查业务数据库、不查 Redis。
2. **客户端用户认证(`@../007.用户系统`)**:面向终端用户的登录与会话,与管理后台账号表、admin JWT 完全独立。
3. **节点 admin 本地认证(`@feat.md`)**:节点本地管理接口的 JWT-only 验签,复用同一支 admin Access Token 做纯验签,但不在节点侧回查数据库或 Redis,也不提供登录 / 续签。
4. **外部 API Key 认证(本域)**:管理员在系统设置页生成 API Key,业务服务器只保存 hash、前缀和生成时间;第三方系统用该 key 访问独立外部 API 分组。API Key 不等价于 admin JWT,不能登录后台,不能调用管理后台接口。

四条边界的服务对象、令牌来源、是否回查存储各不相同,实现上禁止互相混用鉴权依赖。

## 业务流程

### 管理员登录(主流程)

1. 管理员打开后台登录页。
2. 前端请求图片验证码。
3. 管理员输入用户名、密码、验证码。
4. 后端校验验证码 → 查管理员账号表 → 校验密码哈希 → 检查账号启用状态 → 签发 Access / Refresh Token。
5. 前端保存令牌,跳转后台首页。
6. 后续请求携带 Access Token;过期时前端拦截器用 Refresh Token 自动续签并重试一次,续签失败跳回登录页。

### 模块内操作(通用模式)

- 只读模块(Dashboard、订单、下载详情、解析失败排查):进入页面 → 按筛选条件请求列表 → 查看;少数解析失败排查支持对单条触发一次重新解析。
- 受控写入模块(服务节点、系统设置、代理池):列表查看 + 表单 / 对话框写入,关键操作按业务风险使用显式保存或二次确认。
- 节点维度操作:管理员从业务服务器读节点列表后,按目标节点公网地址**直连目标节点本地接口**执行监控相关操作,不经业务服务器代理。

### 异常与分支

- 令牌过期且续签失败:清空令牌,跳登录页。
- 目标节点直连返回鉴权失败:前端回业务服务器续签后重试一次,仍失败则展示节点鉴权失败。
- 删除有活跃请求的客户端:被服务端拒绝,提示活跃请求数。
- 监控采样无效或非 Linux 环境:展示无数据,不影响其他模块。
- API Key 泄漏:管理员在系统设置页重新生成即可让旧 key 失效。
- 外部统计大盘读取部分节点失败:接口仍返回业务统计与其他节点数据,失败节点展示空客户端列表 / 空速率和错误摘要。
- 远端配置文本不是合法 JSON 或顶层不是对象:页面不提交,保留当前输入并提示管理员修正。
- 远端配置读取或保存失败:只影响本标签页,不自动重试;管理员可再次读取或保存。

## 非功能性需求

- 后台是低频内部工具,监控 / 订单等只读页面不承诺大数据量或宽时间窗下的查询性能,只面向人工排查。
- 后台独立域名部署,与 public website 物理隔离;Nginx 对实时推送类接口关闭缓冲并放宽超时。
- 写入操作避免在管理路径直接持有业务长事务,参数校验在 API 层,事务在 service 层。
- 批量删除 / 修改走 SQL 层,不先全量加载再逐行改。
- 后台文案必须支持 i18n(中英文)。
- API Key 原文只在生成成功响应里展示一次;后端数据库、日志和普通查询响应都不保存 / 不回显原文。
- 远端配置是面向多个扩展版本的宽松稀疏对象:允许缺少分组、缺少字段和未知项,不检查字段完整性或字段类型。

## 验收标准

产品视角的关键验收(技术层验收见各 `tech-*.md`):

- 管理员可通过 CLI 创建账号,并用账号密码 + 图片验证码登录后台。
- 登录后进入 Dashboard,能看到正确的用户统计与 60 天按天打点数据;插件商店评价点击按日展示点击次数与独立设备数。
- 系统设置页可手动刷新全部配置读取缓存;成功后后续配置读取使用数据库最新值,失败时展示错误并允许管理员重试。
- 系统设置页可生成 / 重新生成当前管理员的 API Key;生成成功后只展示一次完整 key,刷新页面后只能看到 key 前缀与生成时间。
- 系统设置页的远端配置标签默认显示 `{}`;管理员可保存任意稀疏顶层对象,缺少项和未知项不会被页面拒绝或删除。
- 远端配置标签不展示扩展包内默认值,不提供“恢复默认”、格式化、自动保存、版本选择、历史或回滚;保存成功后提示重新加载 Vimeo 页面生效。
- 使用有效 API Key 可访问外部系统统计大盘;无 key、错 key、已被重新生成覆盖的旧 key 不能访问。
- 系统统计大盘返回今日注册人数、今日付费订单总额、今日履约失败数量与金额、当前节点列表与各节点速率。
- 订单管理可按多维度筛选并查看订单列表与详情,且不存在任何修改订单状态的按钮或接口。
- 点击后台中展示的用户 ID 可打开通用用户信息弹窗;弹窗只读展示用户基础信息、当前 Credits、当前订阅状态、`user_download_records` 最近下载列表和该用户全部订单列表,两个列表均支持分页。
- 下载详情列表只展示下载开始 / 成功 / 失败三类记录,坏数据不导致页面崩溃。
- 解析失败排查可查看失败记录并对单条触发一次重新解析。
- 服务节点管理可新增、编辑、启用 / 停用、手动健康检查节点(节点 CRUD 细节见 `@feat.md`)。
- 节点本机监控可在服务节点列表展示各节点网络进出速率或无数据占位。
- 代理池页面可新增、编辑、启停和删除配置；批量新增任一项失败时整批失败，不展示部分成功结果。
- Access Token 过期前自动续签,过期且续签失败后跳转登录页。
- 中英文切换正常,移动端完整可用:窄屏(<768px)下侧边栏收起为抽屉导航(顶栏汉堡按钮唤起,选中菜单后自动收起),页面无横向溢出,宽表格在卡片内横向滚动。

## 用户操作逻辑与 UI 元素

> 后台 UI 文案需 i18n。所有模块共用一个响应式布局:桌面端为可折叠侧边栏 + 顶栏(登出);移动端(<768px)侧边栏替换为顶栏汉堡按钮唤起的抽屉导航,顶栏展示标题与登出。

### 登录页

- 居中卡片,最大宽度 400px。
- 表单:用户名输入、密码输入、验证码输入 + 验证码图片(120px × 40px,点击刷新)。
- 登录按钮(带 loading),成功后跳首页。

### Dashboard 首页

- 顶部统计卡片:总用户数、今日新增(展示昨日同期人数与变化百分比)、24H 活跃人数、7D 活跃人数。
- 60 天按天数据表格:日期、注册数、各打点类型的事件数 / 设备数,窄屏横向滚动。动态打点列只展示真实写入 `mark_logs` 的网页行为打点(后端返回什么就展示什么,前端不隐藏、不重排),第一列是 `web_first_opened`;插件行为打点只写阿里云 SLS,不进本表格。

### 订单管理页

- 筛选区:订单号、用户 ID、用户当前邮箱、支付渠道单号、订单状态、履约状态、商品、支付方式、创建时间范围。
- 订单表格:订单号、用户 ID、用户当前邮箱、商品、订单状态、履约状态、支付方式、订单金额、实付金额、渠道单号、创建时间、支付时间,以及详情入口。
- 订单表格和详情抽屉中的用户展示是可点击入口,点击打开通用用户信息弹窗。
- 详情抽屉:订单基础信息、商品快照、金额快照、支付信息、时间信息、原始支付数据 JSON、扩展元数据 JSON,支持复制订单号与渠道单号。
- 用户当前邮箱明确标注"当前邮箱,非下单时快照"。
- 不存在任何修改订单状态的按钮或接口。

### 系统设置页

- 页面标题:系统设置。
- 顶部标签栏包含「配置表缓存」「API Key」「远端配置」三个标签,点击切换;各标签的加载或保存失败互不影响。
- 配置缓存区块:普通内容区,展示一个"刷新配置缓存"按钮和最近一次操作结果。
- 刷新配置缓存按钮:主按钮,可点击;点击后进入 loading,调用后台刷新全部配置读取缓存;请求完成后恢复可点。
- 成功结果:展示成功提示和本次刷新时间;管理员可继续重复点击。
- 失败结果:展示失败提示;不做自动重试,管理员可再次点击。
- API Key 区块:展示当前管理员是否已有 API Key、key 前缀、生成时间和"生成 API Key" / "重新生成 API Key"按钮。
- 生成 API Key 按钮:主按钮,首次生成时可直接点击;生成成功后弹窗展示完整 key,提示只展示一次。
- 重新生成 API Key 按钮:危险按钮,点击前二次确认;确认后生成新 key 并立即让旧 key 失效。
- 复制 API Key 按钮:只在生成成功弹窗内显示,点击复制完整 key。
- 远端配置编辑区:一个全宽等宽字体多行文本框,最小高度 360px;首次没有服务端内容时显示 `{}`,不展示扩展包内默认值。
- 远端配置保存按钮:主按钮,管理员点击后才提交;保存中进入 loading 并禁止重复提交。成功后保留原输入并提示重新加载 Vimeo 页面生效。
- 远端配置错误态:JSON 解析失败或顶层不是对象时在编辑区下方提示且不提交;读取失败时显示重试入口;保存失败时保留未保存文本并允许再次点击。
- 远端配置不提供字段表单、字段补全、自动格式化、自动保存、版本选择、“恢复默认”、历史或回滚。管理员要取消全部远端覆盖时手工保存 `{}`。
- 除远端配置这一个明确入口外,本页不提供通用配置值编辑器;也不提供 API Key 多条管理、权限分组或审计列表。

### 外部系统统计大盘

- 第三方系统通过 API Key 请求独立外部 API 分组中的系统统计大盘。
- 返回今日注册人数。
- 返回今日付费订单总额;不按商品类别过滤,履约成功与履约失败都计入,按币种分别返回,不把不同币种金额混加。
- 返回今日履约失败订单数量和金额;该字段用于外部系统重点展示异常收入。
- 返回当前节点列表:每个节点含节点名字与节点下载 / 上传速率。
- 节点不可访问或采样无数据时,该节点保留在列表中,对应客户端列表为空或速率为空,并带错误摘要。

### 下载详情列表页

- 刷新按钮 + 远程分页表格。
- 列:ID、状态(开始 / 成功 / 失败)、媒体平台、节点 ID、地址、文件大小、文件名、错误内容(仅失败行)、时间。
- 字段缺失统一显示占位符;坏数据不崩溃。

### 解析失败排查页

- 远程分页表格:解析失败打点记录。
- 单条操作:对失败链接触发一次重新解析,展示结果。

### 服务节点管理页

节点 CRUD、启用 / 停用、手动健康检查、节点本地运行态诊断。接口规格见 `@tech-服务节点.md`。

### 节点本机监控展示

- 服务节点列表新增"当前速率"列(入站 / 出站两行)。
- 无有效数据、节点停用 / 不健康 / 不可直连时显示占位符。

### 数据分析页

- 顶部标签栏(NTabs)六个只读子页:下载资源分析 / 下载排名 / 下载统计 / 用户地理分析 / 每日充值(+8) / 商品统计(+8),点击切换。
- 每个子页顶部统一筛选区:时间范围选择器(默认最近 24 小时,提供「最近 24 小时」「最近 7 天」快捷,可手动选区间)+ 查询 / 刷新按钮。
- 下载资源分析:表格,列「资源大小(档位) / 次数(消耗积分) / 次数(百分比%) / 次数(总和) / 次数(百分比%)」,固定 12 档(11 个大小档 + 未知大小),空档显示 0;两个百分比分别按当前结果中消耗积分次数总和、全部次数总和计算。
- 下载排名:表格,列「排名 / 用户 ID / 次数(消耗积分) / 次数(总和)」,按总和次数降序取前 20,排名为行号。
- 下载排名里的用户 ID 可点击打开通用用户信息弹窗。
- 下载统计:6 个统计卡片(人数 / 次数 / 资源大小总和,各分「按消耗积分」「总和」),资源大小显示为 MB/GB。
- 用户地理分析:表格,列「地区(国家名,未知显示占位) / 人数」,人数单元格显示为「人数 (百分比%)」,百分比按当前结果总人数计算;地区为注册国家,只有国家粒度。
- 每日充值(+8):表格,列「日期 / 笔数(成功) / 金额(成功) / 笔数(全部) / 金额(全部)」;日期按 UTC+8 自然日,成功为订单状态=已支付,全部为所有订单;金额按币种拆分展示,不混加。
- 商品统计(+8):表格,列「日期 / 商品 ID / 笔数(成功) / 金额(成功) / 笔数(全部) / 金额(全部)」;日期按 UTC+8 自然日,按商品 ID 分组;成功与全部口径同每日充值。
- 各子页无数据显示空态;区间或参数异常展示错误提示,不崩溃。

### 通用用户信息弹窗

- 入口:后台内所有表格或详情里展示的非空用户 ID,包括订单管理用户列 / 详情、数据分析下载排名。
- 弹窗形态:居中 modal,最大宽度约 960px,移动端宽度随视口收缩;关闭按钮位于右上角。
- 顶部信息:用户 ID、邮箱、注册来源、注册方式、注册 IP(归属地)、最后登录 IP(归属地)、最后一次操作 IP(归属地)、注册时间、最后登录时间、登录次数、账号状态。
- 权益信息:当前 Credits 余额、是否有有效订阅、订阅过期时间。订阅已过期时显示未订阅,同时保留过期时间用于排查;从未订阅时过期时间显示占位符。
- 下方 tabs:
  - 「最近下载」:来源为 `user_download_records`,展示平台、链接、source ID、文件名、文件大小、扣除 Credits、下载时间,支持远程分页,不提供筛选。
  - 「积分记录」:来源为 `user_credit_logs`,展示变动时间、积分变动、变动原因、资源 Key 和详情,按流水 ID 倒序远程分页,不提供筛选。
  - 「订单列表」:展示该用户全部订单,成功/失败/待支付/取消/过期都显示,支持远程分页,不提供筛选。
- 异常:用户不存在或接口失败时展示错误提示并允许关闭后重试;字段缺失统一显示占位符。
