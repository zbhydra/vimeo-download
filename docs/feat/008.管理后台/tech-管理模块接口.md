# 008 · 管理模块接口索引

> 本文件只保留 admin 管理模块的通用接口约定与菜单级技术文档索引。各菜单的接口规格、关键 service 行为、错误码映射和实现锚点分散到同目录 `tech-*.md`。
> 关联:`@feat.md` `@tech-后台架构与认证.md` `@tech-节点本地与中心入口.md`。认证接口(登录 / 续签 / 验证码)、JWT claims、错误码总表见 `@tech-后台架构与认证.md`。服务节点 CRUD 接口见 `@tech-服务节点.md`，代理池管理见 `@tech-代理池.md`。

## 通用约定

- 所有 admin 接口前缀 `/api/admin`。
- 所有 admin 接口只用 GET / POST。
- 业务服务器管理接口用 `get_admin_user()`(回查管理员表);节点本地管理接口用 `get_admin_jwt_only()`(只验签)。二者边界见 `@tech-后台架构与认证.md`。
- 响应统一 `{ code, data, msg }`,`code == 10000` 为成功;错误响应在需要时携带 `data`。
- 参数校验在 API 层(schema / route handler),事务在 service 层;service 为类,不写游离函数。
- 批量删除 / 修改走 SQL 层 UPDATE / DELETE,禁止先 SELECT 全量加载再逐行改。
- 模块读取的业务数据(订单、下载记录、打点、积分、用户)的数据模型本身属各自域。

## 拆分规则

- 新增菜单时新增独立 `tech-菜单名.md`,并在本索引登记。
- 同一菜单内的子功能优先放在同一份菜单文档中,避免按接口碎片化。
- 跨菜单共享的认证、路由、部署、令牌续签放在 `@tech-后台架构与认证.md`。
- 节点本地与中心入口的双路由边界放在 `@tech-节点本地与中心入口.md`。
