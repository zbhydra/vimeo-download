# 002 · 数据分析 - 前端页面与组件执行计划

> 配套需求、口径、UI 规格见 `@../feat.md`、`@../tech-数据分析.md`。本计划只列执行步骤、责任边界、验收与回滚。
> **依赖**:无,可与 `@001.数据分析-后端聚合接口.md` 完全并行。联调需后端 4 接口就绪;接口契约已在 tech 定稿,可先按契约 mock 开发。

## 目标

交付 admin「数据分析」菜单:单路由 + 页内 `NTabs` 四标签页,通用 `TimeRangePicker` 时间组件,对接 4 个聚合接口,中英文案齐备。

## 改动范围

| 文件 | 操作 | 责任 |
| --- | --- | --- |
| `admin/src/components/TimeRangePicker.vue` | 新增 | 通用时间范围选择器(datetimerange + 24H/7D 快捷) |
| `admin/src/api/analytics.ts` | 新增 | 4 个 `getXxx` + 请求/响应 interface |
| `admin/src/views/AnalyticsView.vue` | 新增 | 单文件容器，`NTabs` 内联 4 个 `NTabPane` |
| `admin/src/router/index.ts` | 修改 | 加 `{ path: "analytics", name: "Analytics" }` |
| `admin/src/layouts/AdminLayout.vue` | 修改 | `menuOptions` + `routeMap` 加 Analytics 项 |
| `admin/src/i18n/zh-CN.json` `en-US.json` | 修改 | 加 `layout.analytics` + `analytics` 段 |

## 执行步骤

### 1. TimeRangePicker.vue

- 封装 `<NDatePicker type="datetimerange">`,`v-model` 为 `[number, number] | null`(毫秒)。
- `:shortcuts` 两个:「最近 24 小时」「最近 7 天」,点击时取 `Date.now()` 计算(写法见 tech「时间范围选择器组件」)。
- 组件受控、无副作用;默认 24H 由父组件初始化。

### 2. api/analytics.ts

- 仿 `api/orders.ts` 模式:interface 字段带 JSDoc;`request.get<never, T>("/download-analytics/xxx", { params })`。
- 4 个函数 + 类型:`getResourceDistribution` / `getTopUsers` / `getDownloadSummary` / `getUserGeo`,参数 `{ from_ms: number; to_ms: number }`,返回类型对应 tech「接口」响应(`buckets` / `users` / 6 标量 / `regions`)。

### 3. AnalyticsView.vue(单文件,4 tab 内联)

- `NTabs` 4 个 `NTabPane`:下载资源分析 / 下载排名 / 下载统计 / 用户地理分析(标签用 `t()`)。
- 每个 pane 内:`NCard` → header(`TimeRangePicker` + 「查询」主按钮 + 「刷新」)→ body。
  - 资源分析/排名/地理:`NDataTable`(资源分析固定 12 行;排名排名列用前端行号;地理国名用 `Intl.DisplayNames(useI18n().locale, {type:'region'})` 转,`unknown`→「未知」,降级显示原码)。
  - 下载统计:6 个 `NStatistic` 卡片(3×2 grid),资源大小格式化为 MB/GB。
- 每个 pane 各自 `timeRange` 状态(默认 `[now-24h, now]`)、`loading`、数据 ref、`load()`(try/catch/finally,catch 内 `console.error("AnalyticsView.xxx 失败:", error)` + `message.error(t(...))`)。
- `onMounted` 触发首个(激活)pane 的首次加载;切 tab 时,目标 pane 未加载过则触发加载,已加载不重复请求。

### 4. 路由 + 菜单

- `router/index.ts`:`/` children 加 `{ path: "analytics", name: "Analytics", component: () => import("@/views/AnalyticsView.vue"), meta: { requiresAuth: true } }`。
- `AdminLayout.vue`:`menuOptions` 加一项(`key: "Analytics"`,图标取 `@vicons/antd` 如 `BarChartOutlined`);`routeMap` 加 `Analytics: "/analytics"`。

### 5. i18n

- `zh-CN.json` / `en-US.json` 同步:`layout.analytics`(菜单名);新增 `analytics` 段(4 tab 标题、列名「资源大小/次数(消耗积分)/次数(总和)/排名/用户ID/地区/人数」、筛选按钮「查询/刷新」、统计卡片标签、空态文案、「最近 24 小时」「最近 7 天」)。

## 验收标准

- 菜单「数据分析」可见、可点、高亮正确;4 tab 可切换,默认激活第一个。
- 每个 tab 默认 24H 自动加载;「最近 24 小时」「最近 7 天」快捷与手动区间都能正确触发查询并刷新。
- 资源分析恒 12 行(空档显示 0);排名 ≤20 行带行号;统计 6 卡片;地理国名显示中文(`unknown`→「未知」)。
- 空数据显示空态;接口失败弹错误提示且不崩溃。
- `pnpm tsc --noEmit` + `pnpm build` 通过;中英文案 key 齐全(切语言不报缺 key——注:语言切换 UI 不在本计划范围)。

## 风险与回滚

- 新增 3 个文件独立;回滚 = 删 `TimeRangePicker.vue` / `AnalyticsView.vue` / `analytics.ts` + 还原 `router/index.ts`、`AdminLayout.vue`、两份 i18n json 的新增段。
- 风险点:`NTabs` 切换的加载时机勿重复请求;`Intl.DisplayNames` 需 try/catch 降级;国名 locale 取 `useI18n().locale.value`(当前固定 `zh-CN`);禁 `any`/`unknown`,类型仿 `orders.ts`。
