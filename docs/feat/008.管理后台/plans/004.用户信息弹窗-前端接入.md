# 004 · 用户信息弹窗前端接入

## 目标

新增可复用 `UserInfoDialog` 组件,把后台内已有用户 ID 展示位置接入弹窗,并统一后台时间展示格式。

## 依赖 plan

- `003.用户信息弹窗-后端接口.md`

## 改动范围

- 新增 `admin/src/api/users.ts`
- 新增 `admin/src/components/UserInfoDialog.vue`
- 新增 `admin/src/utils/time.ts`
- 修改 `admin/src/views/OrdersView.vue`
- 修改 `admin/src/views/AnalyticsView.vue`
- 修改已有 admin 页面里 `toLocaleString()` / 本地时间格式函数,统一调用 `admin/src/utils/time.ts`
- 修改 `admin/src/i18n/zh-CN.json`
- 修改 `admin/src/i18n/en-US.json`
- 更新 `admin/e2e/orders.spec.ts`,新增 `admin/e2e/analytics.spec.ts` 覆盖用户 ID 入口。

## 文件或模块责任

- `users.ts`:封装 profile、downloads、orders 三个 API,声明响应类型和分页参数。
- `UserInfoDialog.vue`:内部管理弹窗打开、profile loading、downloads/orders 分页 loading、空态与错误态。
- `utils/time.ts`:固定按 UTC+8 输出 `YYYY-MM-DD HH:mm:ss`,禁止后台展示继续使用浏览器 locale 默认格式。
- `OrdersView.vue`:订单列表用户列和详情抽屉用户项可点击打开弹窗。
- `AnalyticsView.vue`:下载排名用户 ID 可点击打开弹窗。
- `ServiceNodesView.vue`:节点当前使用明细用户 ID 可点击打开弹窗。
- `TgClientView.vue`:当前使用明细非空用户 ID 可点击打开弹窗。
- i18n:新增 `userInfo` 文案段,中英文同步。

## UI 验收

- 点击订单、下载排名、节点当前使用明细中的用户 ID 都打开同一个弹窗。
- 弹窗展示用户 ID、邮箱、注册来源、注册 IP(归属地)、最后登录 IP(归属地)、最后一次操作 IP(归属地)、Credits、订阅状态。
- 「最近下载」tab 展示 `user_download_records` 分页列表,不提供筛选。
- 「订单列表」tab 展示该用户全部订单,成功/失败/待支付/取消/过期都显示,不提供筛选。
- admin 所有已有时间展示均为 `YYYY-MM-DD HH:mm:ss`,固定 UTC+8。
- `user_id=null` 显示 `-`,不可点击。
- 缺失字段显示 `-`;接口失败 toast 提示,页面不崩溃。
- 移动端 modal 不横向溢出,表格可横向滚动。

## 风险与回滚

- 风险:多个页面各自持有一个弹窗 ref,实现重复。接受该成本,避免引入全局状态或依赖注入。
- 风险:表格用户 ID 链接与行内按钮抢点击。实现时用户 ID 自身作为按钮,不要绑定整行点击。
- 回滚:移除三个页面中的弹窗组件和用户 ID click 渲染,保留 API 文件也不影响现有页面;需要彻底回滚时同时删除新增组件和 i18n key。
