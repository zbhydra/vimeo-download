# 003 · 好评赠送订阅 - 后端

## 目标

交付永久领取次数、订阅配置响应、账号级 Redis 短锁和 7 天订阅加时接口。

## 依赖 plan

无。完成后 `@../../011.Pricing页/plans/001.好评赠送订阅-Pricing前端.md` 才能联调。

## 改动范围

1. 注册 `SUBSCRIPTION_REVIEW_REWARD_CLAIMED=6001` 永久 Counter。
2. 扩展订阅 checkout 配置响应和可选鉴权。
3. 抽取统一订阅按天加时能力,保持支付履约与赠送共用算法。
4. 新增领取 API、5 秒 Redis 锁、1 秒抢锁超时和服务器繁忙错误。
5. 增加全部后端语言错误文案与真实 MySQL + Redis 测试。

## 验收标准

- 匿名配置返回次数 0;登录配置返回真实次数。
- 首次领取只增加一次 Counter 和 7 天订阅。
- 重复领取成功跳过;并发请求不重复赠送。
- Redis 不可用或抢锁超时返回服务器繁忙且无 DB 写入。
- 两事务顺序和部分失败风险与技术规格一致。
- 无新 Model、索引、依赖注入、锁续租、补偿或第三方依赖。

## 风险与恢复

- Counter 提交后订阅失败会永久失去本次赠送,已明确接受且不补偿。
- 临界区超过 5 秒时锁可能到期;若后续请求在首个 Counter 提交前进入,极低概率可能重复赠送,不增加续租或第二套幂等协议。
- 回滚方式为下线领取入口或回退 API 路由;已写入 Counter 和已增加订阅不回退。
