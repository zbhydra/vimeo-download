## 系统定性

订阅系统重新激活为**插件专属权益域**。它只定义 extension 下载权益,不定义 website 下载权益。

- Free 是正式订阅档位,当前 extension 每日 3 次;任一作用域首次下载当天不限次(首日免费,见 `@../005.计数器系统/feat.md`)。
- Unlimited Download 在同一时刻采用一种计费模式和一个周期,有效期内 extension 每日下载不限次数;计费合同见[订阅商品与状态](tech-订阅商品与状态.md#商品与渠道价格)。
- 购买入口只在 website pricing 页,见 `@../011.Pricing页/feat.md`。
- extension 不再承载订阅套餐购买页;旧 options 订阅卡和订阅提示弹窗已删除。
- website 下载继续走 Credits,购买 Unlimited 不赠送 Credits、不改变 website 扣费。

## 功能目标

为浏览器插件提供可配置的订阅权益:

1. 免费用户也有明确的每日下载额度。
2. 付费用户通过 Unlimited Download 获得插件不限次数下载,当前商品配置决定一次性或自动续费模式。
3. 订阅状态可被 extension 状态接口与已登录账号摘要读取。
4. 自动续费成功时延长订阅有效期,到期未续费时回到 Free。
5. 有效自动续费订阅可从 Pricing 进入当前支付渠道管理后续扣款。
6. 未领取过好评赠送的账号可从 Pricing 购买确认流程领取一次 7 天 Unlimited 权益。

## 功能范围

### 包含

- 订阅商品定义:Free 与 Unlimited Download。
- 订阅权益:extension 每日下载次数上限。
- 用户订阅状态:当前档位、生效/到期时间。
- 订阅到期降级:有效期结束后自动回到 Free。
- 订阅状态查询:给 extension 展示和计数器解析额度使用。
- 与自动续费账单衔接：PayPal / Clink 首期成功、后续续费成功、到期降级。
- 已有未过期 Unlimited 时拒绝普通重复购买;不增加并发锁或渠道协议状态机来保证绝不会重复订阅。
- Pricing 提供自动续费订阅的支付渠道管理入口。
- 好评赠送订阅：活动开关启用时，每个网站账号最多领取一次，领取后直接延长 7 天 Unlimited 权益。领取资格按网站账号与设备两个维度去重：同一浏览器上的第二个账号领不到。
- 旧插件兼容字段:在可控范围内继续返回标量字段,但值应镜像当前 extension 下载额度。

### 不包含

- website 下载额度或 website 无限下载;website 下载只走 Credits。
- Credits 余额、扣费、积分包购买。
- 下载解析、下载执行、节点调度。
- 退款、补偿、发票、税务、对账。
- 其他订阅档位、多席位、优惠码。
- extension 端直接拉起支付;购买入口首版只在 website pricing 页。
- extension options 订阅套餐页、订阅卡片、插件内订阅支付提示弹窗。
- 站内不直接执行取消;用户在支付渠道管理入口中操作。
- 取消后的退款、按比例退费、立即降级。
- 到期前恢复自动续费;已取消续费的用户仍等到订阅到期后重新购买。
- 注册试用订阅的新设计;注册赠送 Credits 属于积分系统。
- 验证用户是否真实提交好评、读取评价内容或与 Chrome Web Store 账号关联。
- 证明领取去重维度真实归属：账号与设备都由客户端自证，不校验是否属于同一真人。
- 好评赠送的补偿、对账、人工补发和倒计时恢复。

## 订阅档位

| 档位 | 价格 | 购买方式 | extension 权益 | website 权益 |
| --- | --- | --- | --- | --- |
| Free | `$0` | 默认档位,不可购买 | 3 次/天;首次下载当天不限次 | 无;website 下载走 Credits |
| Unlimited Download | 商品默认展示价 | 当前商品模式下可用的 PayPal / Clink 渠道 | 不限次数 | 无;website 下载走 Credits |

商品卡展示默认价;选择支付渠道后,支付弹窗展示该渠道的实际结算价。

## 业务流程

### 免费用户下载

1. 用户未购买 Unlimited 时处于 Free 档。
2. extension 下载前调用计数器系统扣减当日次数。
3. 当天未超过 3 次时允许下载。
4. 超过 3 次时不扣减,extension 展示升级引导,引导到 website pricing 页。
5. 该作用域首次下载当天不受次数限制,自次日起才按 3 次/天。

### 购买 Unlimited

1. 用户在 website pricing 页选择 Unlimited Download。
2. 如用户已有未过期 Unlimited,pricing 页订阅按钮灰化;点击后提示存在有效订阅,不可重复购买。
3. 无有效 Unlimited 时,pricing 页按商品当前模式和可用渠道创建一次性支付或自动续费订阅。
4. 支付成功后,一次性购买按商品自然月周期延长权益,自动续费按渠道实际已付账期生效;计费规则见 [`tech-订阅商品与状态.md` 的“商品与渠道价格”](./tech-订阅商品与状态.md#商品与渠道价格)。
5. 用户刷新 extension 订阅状态后,extension 下载额度变为不限。

购买页面、支付确认、轮询和异常见 `@../011.Pricing页/feat.md`。

### 自动续费

1. 支付渠道在每个周期自动扣款。
2. 扣款成功后,系统延长订阅有效期。
3. 扣款失败时,当前已付周期内权益保留;到期仍未续费则回到 Free。
4. 重复 webhook 不重复延长同一周期。

### 领取好评赠送订阅

1. 系统读取好评赠送活动开关;关闭、缺失或配置非法时不展示入口且不允许领取。
2. 未领取账号在 Pricing 的订阅购买确认中选择“去好评”。
3. Pricing 打开插件的 Chrome Web Store 评价页,并在原页面显示 30 秒检测倒计时。
4. 倒计时结束后，系统按网站账号与设备两个维度检查是否已领取；任一维度已领取即按已完成返回。
5. 未领取时先记录本次领取,再把当前订阅到期时间增加 7 天;无有效订阅时从当前时间起算 7 天。
6. 已领取时不再增加订阅,按已完成返回。
7. 领取成功后 Pricing 刷新账号订阅状态,不再进入本次付费购买。

领取会把当时可用的两个维度一并标记。两个维度都是客户端自证，只提高门槛、不防恶意用户。

该流程不验证真实评价。界面与交互见 `@../011.Pricing页/feat.md`,技术合同见 `@tech-好评赠送订阅.md`。

### 管理自动续费

1. 已登录用户在 website Pricing 页查看当前 Unlimited。
2. 存在未过期且仍自动续费的 Unlimited 时,页面展示“管理订阅”按钮。
3. Clink 用户进入 Customer Portal，PayPal 用户进入 Automatic Payments 通用页。
4. 用户在支付渠道中管理后续扣款;打开入口本身不改变本站订阅状态或当前周期权益。

### 订阅状态查询

1. 已登录用户按账号读取订阅状态。
2. 匿名用户按 Free 档处理,并用 device_id 统计当日已用次数。
3. 状态返回当前权益、当日已用、剩余次数、重置日期。
4. website 下载不读取订阅状态决定扣费。

### extension 升级入口

1. extension popup 或内容页只展示当前额度状态、额度不足升级引导和登录入口。
2. 用户点击升级按钮时,插件打开官网 pricing 页。
3. 官网 pricing 页负责登录、套餐展示、支付确认、订单轮询和订阅生效。
4. 插件端不展示旧订阅方案,不展示购买卡片,不弹插件内订阅支付提示。

## 异常流程

- 自动续费首期支付失败:不生效 Unlimited,用户仍为 Free。
- 已有有效 Unlimited 时再次购买:前端订阅按钮灰化并提示不可重复购买;后端下单校验同样拒绝创建订阅订单。
- 用户在两个未完成的 checkout 中分别确认付款:不做并发锁或跨渠道协议协调;两笔成功付款按正常订单履约,极少数重复订阅由支持处理。
- 后续续费失败:当前周期到期前保持权益,到期后降级。
- 支付渠道管理入口创建失败:不修改订阅,用户可重试。
- webhook 重复到达:不重复延长。
- 订阅状态读取失败:前端展示重试;下载扣减失败仍按计数器系统 fail-open 口径。
- 支付成功但订阅写入失败:进入自动续费账单补偿/人工排查,用户看到“开通异常,请联系支持”。
- 好评赠送活动关闭、配置缺失或配置非法:不展示入口;旧页面或直接请求领取时返回请求无效,不写领取记录或订阅。
- 好评赠送抢锁失败或 Redis 不可用:返回服务器繁忙,用户可在检测界面直接重试。
- 好评赠送领取资格判定失败:按不可领处理并隐藏入口;领取请求本身按失败返回,用户可重试。
- 好评赠送领取记录已存在:按已领取完成,不报错、不重复加时。
- 好评赠送领取记录已写入但订阅加时失败:本次返回失败;不回滚领取记录、不补偿,后续请求按已领取跳过。
- 好评赠送领取接口缺设备标识:返回参数错误,不产生任何写入;插件无法提供设备标识时领取入口不可用。

## 非功能性需求

- 不新增第三方依赖;不新增依赖注入。
- 订阅配置、价格、权益只走配置表,不写死在前端。
- 文案需 i18n。
- 不做金融级对账;失败让用户重试,已支付未履约走补偿或人工排查。
- 好评赠送只使用 5 秒 Redis 短锁,不续租、不增加复杂状态机或跨数据库事务。
- 所有时间口径以服务器系统时区为准。
- 旧插件兼容字段不得突然删除。

## 验收标准

- Free 用户每日 extension 下载上限为 3 次。
- Unlimited 有效用户 extension 下载上限为不限次数。
- 未登录匿名设备按 Free 3 次/天计数。
- 作用域首次下载当天不限次数;自次日起按档位上限,且首日不消耗当天次数。
- website 下载不受订阅影响,仍只扣 Credits。
- Unlimited 可通过 pricing 页使用当前商品模式下的可用支付渠道购买;页面不同时提供一次性与自动续费选项。
- 已有有效 Unlimited 时不能再次购买 Unlimited,点击灰化订阅按钮会提示存在有效订阅。
- 有效且自动续费的 Unlimited 用户可在 Pricing 页进入当前支付渠道的管理入口。
- extension options 不再出现订阅套餐购买页;旧订阅卡片和插件内订阅提示弹窗已移除或不再被引用。
- 订阅状态接口能返回当前档位、到期时间、当日 extension 已用/剩余/上限。
- 旧标量额度字段镜像当前 extension 下载上限。
- 续费 webhook 重复到达不重复延长权益。
- 未领取账号可领取一次 7 天 Unlimited;无有效订阅时从当前时间起算,有效订阅时从原到期时间继续增加。
- 已领取账号再次请求时不重复加时，并按已领取成功返回；按网站账号或设备任一维度命中即视为已领取。
- 同一浏览器上的第二个账号领不到 7 天。
- 并发领取由账号级 5 秒 Redis 锁串行化;1 秒内抢不到锁返回服务器繁忙,锁之外的重复请求也不会二次加时。
- 领取记录与订阅分别提交;记录已提交而订阅加时失败时不补偿。
- 好评赠送活动关闭时页面不展示入口,领取接口不产生任何业务写入。

## 用户操作逻辑与 UI 元素

### extension 订阅状态展示

extension UI 只做状态展示和升级引导,不做套餐选择和购买。

| 元素 | 形式 | 可点击 | 行为 |
| --- | --- | --- | --- |
| 当前档位 | 文本 | 否 | 展示 Free 或 Unlimited Download |
| 次数计数器 | 文本 | 否 | Free 展示剩余/每日上限;Unlimited 隐藏或展示 Unlimited |
| 升级按钮 | Free 为琥珀色渐变主按钮(白字加粗,带 2.2s 循环光晕呼吸动效,悬停上浮 1px 并暂停动效);Unlimited 为白底灰边次级按钮 | 是 | 打开 website pricing 页 |
| 到期提示 | 文本 | 否 | Unlimited 显示到期或续费状态 |
| 管理订阅 | 按钮 | 是 | 有效自动续费时进入当前支付渠道管理入口 |

升级按钮的醒目样式只给 Free 用户:与头部蓝色登录按钮形成互补色对比,是 Popup 头部最先被看到的元素;Unlimited 文案保持低调,避免误导已付费用户继续升级。动效遵循系统"减少动态效果"设置,开启时不播放光晕与上浮。

旧 options 订阅套餐页不是当前产品界面。`SubscriptionPlans` 这类插件内购买组件、`options_page` 入口和打开 options 的升级路径都应保持删除状态。
