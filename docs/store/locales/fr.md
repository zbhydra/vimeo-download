Téléchargez les vidéos Vimeo en MP4, enregistrez l'audio en MP3 ou M4A et les sous-titres en fichiers VTT, directement depuis la page que vous regardez. Démarrage gratuit.

Vimeo Downloader ajoute un panneau de téléchargement aux pages Vimeo compatibles. Inutile de copier des liens dans un autre site : l'extension fonctionne dans votre propre navigateur.

Ce que vous pouvez enregistrer :

- Vidéo : toute qualité proposée par la source, jusqu'en 4K, en MP4.
- Audio : uniquement le son, en M4A ou MP3.
- Sous-titres : chaque langue disponible dans un fichier VTT, y compris les pistes générées automatiquement. Un fichier VTT s'ouvre dans n'importe quel éditeur de texte et sert de transcription horodatée.
- Vignette : l'image de couverture de la vidéo.
- Extrait : coupez une plage de temps d'une qualité DASH ou HLS avant le téléchargement.

Conçue pour les longues vidéos :

- Mettez plusieurs téléchargements en file d'attente et continuez à naviguer.
- Gérez les gros fichiers avec le découpage automatique ou le mode de flux vers un seul fichier.
- Suivez la progression, les fichiers terminés, les échecs et l'historique dans le popup.

L'extension fonctionne sur les pages compatibles de vimeo.com et player.vimeo.com. Elle lit les informations du média sur la page et ne contourne ni connexion, ni paywall, ni DRM, ni aucun autre contrôle d'accès. Téléchargez uniquement les contenus que vous avez le droit d'enregistrer. Vimeo Downloader est un outil indépendant, sans lien avec Vimeo, Inc.

Usages courants : enregistrer une leçon de cours autorisée, une revue de portfolio, une démo de produit, un entretien ou un extrait de référence pour le regarder hors ligne ou le monter.

Fonctionnement : ouvrez une page Vimeo compatible, choisissez dans le panneau ou le popup la vidéo, l'audio, les sous-titres ou l'image, puis la qualité ou la langue. La tâche rejoint la file d'attente et le popup affiche son état pendant que vous continuez à naviguer.
