在你有權保存內容的前提下，用更直接、清楚的流程下載 Vimeo 媒體。

Vimeo Downloader 會將下載控制直接加入支援的 Vimeo 頁面。你可以在正在觀看的頁面完成操作，不必複製連結到其他下載服務。只要來源頁面提供相應資源，就能選擇影片畫質、單獨保存音訊，或下載封面圖。

主要優點：

- 選擇來源頁面提供的任意影片畫質。
- 影片、音訊和封面圖分開輸出，依需要保存。
- 使用 Premium 在下載前裁剪 DASH/HLS 時間片段，只保留需要的部分。
- 將多個任務加入佇列，下載時繼續瀏覽頁面。
- 大型檔案支援自動分割，或以單一檔案串流方式處理。
- 在彈出視窗查看佇列進度、完成狀態、失敗原因和下載記錄。

擴充功能支援 vimeo.com 與 player.vimeo.com 的指定頁面，會讀取頁面中的媒體中繼資料，但不會繞過登入、付費、DRM 或其他存取控制。請只下載你有權保存的內容。

適合保存你有權使用的 Vimeo 課程、作品集、產品示範、訪談或參考片段，用於離線觀看或後續編輯。頁面內的同一套流程可以集中處理影片、音訊和封面圖，輸出格式與畫質以來源頁面提供的選項為準。

使用時開啟支援的 Vimeo 頁面，選擇影片、音訊或封面圖，再選擇可用畫質並加入佇列。你可以繼續瀏覽，並在彈出視窗查看進度、失敗與完成狀態。對於支援的 DASH/HLS 媒體，Premium 可以只下載需要的時間片段。

對於需要保存多個來源或多種畫質的專案，佇列可以集中管理任務，避免反覆開啟下載視窗。影片下載、音訊下載、封面下載和大型檔案處理都能從同一個彈出視窗查看，適合課程資料、作品展示、客戶交付前的授權素材整理等情境。來源頁面沒有提供的畫質或媒體資源，不會由擴充功能虛構或強行產生。
