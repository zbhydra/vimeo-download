把 Vimeo 影片下載為 MP4，音訊存為 MP3 或 M4A，字幕存為 VTT 檔案，直接在你正在看的頁面上操作。可免費開始使用。

Vimeo Downloader 會在支援的 Vimeo 頁面上加入下載面板。擴充功能在你自己的瀏覽器裡執行，不需要把連結複製到其他網站。

可以儲存：

- 影片：來源提供的任意畫質，最高 4K，儲存為 MP4。
- 音訊：只儲存聲音，格式為 M4A 或 MP3。
- 字幕：每種可用語言儲存為一個 VTT 檔案，包括自動產生的字幕軌。VTT 可以用任何文字編輯器開啟，也可以當作帶時間戳記的逐字稿使用。
- 封面圖：影片的封面。
- 片段：選擇 DASH 或 HLS 畫質時，可以先裁剪時間範圍再下載。

適合長影片：

- 把多個下載加入佇列，下載時可以繼續瀏覽。
- 大型檔案可以自動分割，也可以用單一檔案串流模式下載。
- 在彈出視窗查看進度、已完成檔案、失敗項目和下載紀錄。

擴充功能在支援的 vimeo.com 和 player.vimeo.com 頁面上運作。它從頁面讀取媒體資訊，不會繞過登入、付費牆、DRM 或其他存取限制。只下載你有權儲存的內容。Vimeo Downloader 是獨立工具，與 Vimeo, Inc. 沒有關聯。

常見用途：儲存經授權的課程、作品集評審、產品示範、訪談或參考片段，用於離線觀看或剪輯。

使用方法：開啟支援的 Vimeo 頁面，在面板或彈出視窗中選擇影片、音訊、字幕或圖片，再選擇畫質或語言。工作進入佇列後，你可以繼續瀏覽，並在彈出視窗查看狀態。
